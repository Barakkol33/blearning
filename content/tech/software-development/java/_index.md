# ‏Java

מדריך Java למתחילים: מה צריך לדעת, עם דוגמאות קוד קצרות ומלכודות נפוצות.

## מונחים בסיסיים

- **תוכנית**: רצף הוראות שהמחשב מבצע לפי הסדר.
- **מהדר (קומפיילר)**: תוכנה שבודקת את הקוד ומתרגמת אותו לשפה שהמחשב מריץ.
- **משתנה**: תא בזיכרון עם שם וטיפוס, ששומר ערך.
- **טיפוס**: איזה סוג ערך נשמר: מספר שלם, מספר עשרוני, תו, מחרוזת, אמת או שקר.
- **ביטוי**: צירוף של ערכים ופעולות שמחושב לערך אחד, למשל `3 + 4 * 2`.
