# מדריך קלוד (Claude)

מדריך מעשי לשימוש טוב יותר בבינה מלאכותית, גם אם מעולם לא כתבתם קוד.

המדריך בנוי משלוש מדרגות. כל מדרגה מסתמכת על הקודמת, אבל אפשר לעצור בכל אחת מהן ולהישאר עם משהו שעובד:

1. [צעדים ראשונים](01-first-steps/first-steps.md): מתקינים את קלוד ואת Obsidian, ומכירים סוגי קבצים ואפליקציות שימושיים. בלי קוד ובלי טרמינל.
2. [בסיס](02-basics/basics.md): עובדים עם קלוד קוד בתוך VS Code, ויוצרים מסמכים, מצגות ואתרים.
3. [מתקדם](03-advanced/advanced.md): שורת הפקודה, Python, Git והרשאות.
