# אלגברה לינארית 1

מערכות משוואות לינאריות, מטריצות ודטרמיננטות, מרחבים וקטוריים, בסיס וממד והעתקות לינאריות.

## מונחים בסיסיים

- **מרחב וקטורי**: קבוצה עם חיבור וכפל בסקלר שמקיימים את האקסיומות.
- **בסיס**: קבוצה בלתי תלויה שפורשת את המרחב.
- **ממד**: מספר האיברים בבסיס.
- **דטרמיננטה**: מספר שמתאים למטריצה ריבועית; שונה מ-0 אם ורק אם היא הפיכה.

## דגשים

- תמיד בודקים קודם אם המטריצה ריבועית ואם היא הפיכה.
- כדי להראות שקבוצה היא בסיס מספיק להראות שני דברים מתוך שלושה: אי-תלות, פרישה, מספר איברים כממד.
- משפט הממדים: $\dim \ker T + \dim \operatorname{Im} T = \dim V$.
