# מונחים בסיסיים

- **O גדול**: חסם עליון אסימפטוטי על קצב הגידול.
- **ערימה**: עץ בינארי כמעט שלם שבו כל הורה גדול מילדיו (ערימת מקסימום).
- **טבלת גיבוב**: מבנה שממפה מפתחות לתאים בעזרת פונקציית גיבוב; O(1) בממוצע.
- **עץ חיפוש בינארי**: בכל צומת: משמאל קטנים ממנו, מימין גדולים ממנו.
- **משפט האב**: פתרון לנוסחאות נסיגה מהצורה T(n) = aT(n/b) + f(n).
