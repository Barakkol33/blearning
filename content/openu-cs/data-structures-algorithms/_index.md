# מבני נתונים ומבוא לאלגוריתמים

ניתוח אלגוריתמים, מיונים ומבני נתונים בסיסיים: ערימות, טבלאות גיבוב ועצי חיפוש.

## מונחים בסיסיים

- **O גדול**: חסם עליון אסימפטוטי על קצב הגידול.
- **ערימה**: עץ בינארי כמעט שלם שבו כל הורה גדול מילדיו.
- **טבלת גיבוב**: מבנה שממפה מפתחות לתאים בעזרת פונקציית גיבוב.
- **עץ חיפוש בינארי**: משמאל לכל צומת קטנים ממנו, ומימין גדולים ממנו.

## דגשים

- בשאלות הוכחה כותבים את האינווריאנטה במפורש.
- לכל נוסחת נסיגה בודקים קודם אם משפט האב מתאים.
- בפתרון בוחרים מבנה נתונים קיים ומרחיבים אותו, במקום להמציא חדש.
