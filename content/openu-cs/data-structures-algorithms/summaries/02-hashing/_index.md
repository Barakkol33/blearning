# טבלאות גיבוב

טבלת גיבוב שומרת כל מפתח בתא $h(k)$. כששני מפתחות נופלים לאותו תא יש **התנגשות**:

- **שרשור**: כל תא מחזיק רשימה. זמן ממוצע $O(1 + \alpha)$, כאשר $\alpha = n/m$ הוא מקדם העומס.
- **מיעון פתוח**: מחפשים תא פנוי אחר (בדיקה לינארית, ריבועית, גיבוב כפול).

שיטת החילוק: $h(k) = k \bmod m$. כדאי לבחור $m$ ראשוני שאינו קרוב לחזקה של 2.
