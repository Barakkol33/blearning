# מונחים בסיסיים

- **גבול של סדרה**: aₙ → L אם לכל ε > 0 קיים N כך שלכל n > N מתקיים |aₙ − L| < ε.
- **סופרימום**: החסם העליון הקטן ביותר.
- **רציפות**: lim f(x) = f(a) כש-x → a.
- **נגזרת**: גבול מנת ההפרשים (f(a+h) − f(a))/h.
- **משפט לגרנז'**: יש נקודה שבה הנגזרת שווה לשיפוע המיתר.
