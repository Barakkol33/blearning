# מונחים בסיסיים

- **Stack / Heap**: מחסנית: משתנים מקומיים שמשתחררים אוטומטית. ערימה: הקצאה דינמית.
- **Endianness**: סדר הבתים של מספר בזיכרון.
- **Smart pointer**: מצביע שמשחרר את הזיכרון לבד (unique_ptr, shared_ptr).
- **VTABLE**: טבלת פונקציות וירטואליות שמאפשרת פולימורפיזם.
- **Buffer overflow**: כתיבה מעבר לגבולות מערך; פרצת אבטחה קלאסית.
