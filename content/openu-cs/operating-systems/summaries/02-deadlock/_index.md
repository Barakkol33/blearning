# קיפאון

קיפאון קורה רק כשכל ארבעת התנאים מתקיימים:

1. **מניעה הדדית**: משאב בשימוש של תהליך אחד בלבד.
2. **החזק והמתן**: תהליך מחזיק משאב ומחכה לאחר.
3. **אין הפקעה**: אי אפשר לקחת משאב בכוח.
4. **המתנה מעגלית**.

**מניעה נפוצה:** לקבוע סדר גלובלי על המשאבים ולתפוס אותם רק בסדר עולה. זה שובר את ההמתנה המעגלית.
