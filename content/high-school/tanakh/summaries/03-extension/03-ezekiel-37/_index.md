# יחזקאל לז 1-14 - חזון העצמות היבשות

**נושא: הנביאים - לחורבן ולשיבת ציון**

**חורבן** ו**שיבת ציון** הן **שתי תקופות שונות**. **שיבת ציון** - **גאולה**, **חזרה לארץ**, **תקווה**. יש נבואות **על** החזרה לארץ, ויש פרקים שבהם העם **כבר בארץ**.

## מהו חזון?

- **חזון** - אירוע ש**רק הנביא** רואה ושומע. (מכאן המילה **"מחזה"** - אבל **מחזה** כל אחד יכול לראות.)
- כדי **להעביר** את החזון לעם, הנביא מספר אותו כ**משל** - ומסביר את **הנמשל**.

## החזון

1. **"היתה עלי יד ה', ויוציאני ברוח ה'"** - ה' מביא את יחזקאל ל**בקעה מלאה עצמות** - **"והנה יבשות מאוד"**.
2. **"בן אדם, התחיינה העצמות האלה?"** - יחזקאל עונה **"אדוני ה', אתה ידעת"**.
3. ה' מצווה עליו **להינבא** אל העצמות. העצמות **מתקרבות** ("**עצם אל עצמו**"), ועליהן **גידים**, **בשר** ו**עור**.
4. **אבל אין בהן רוח** - הן **גופות**, עדיין **לא חיות**.
5. יחזקאל מנבא **אל הרוח**: **"מארבע רוחות בואי הרוח"** - **"ויחיו, ויעמדו על רגליהם, חיל גדול מאוד מאוד"**.

## המשל והנמשל

| **משל** | **נמשל** |
|---|---|
| **העצמות** | **בני ישראל** - **"העצמות האלה - כל בית ישראל המה"** |
| **יבשות** = **מוות** | **הגלות**: **"יבשו עצמותינו ואבדה תקוותנו"** (פסוק 11). לעם **לא נשאר כמעט כלום** ממרכיבי עם: **ארץ, ריבונות, הנהגה, צבא, מרכז פולחן** - **"מוות כעם"** |
| **הקברים** | **הגלות** (המקום) - **"הנה אני פותח את קברותיכם"** |
| **תחיית העצמות** | **החזרה לארץ** - **"והבאתי אתכם אל אדמת ישראל"** |

### שתי דרכים להבין את החזון

1. **משל** - **תחייה לאומית**, לא תחיית מתים ממש: העם **"מת"** בגלות ו**קם לתחייה** כשחוזר לארצו. (בתקופת **התנ"ך** הרעיון של **תחיית המתים** עוד **לא היה קיים**.)
2. **תחיית המתים** - רעיון ש**נוצר מאוחר יותר**, ואפשר לקרוא את החזון גם כך.

**מהחזון לעברית**: **"קרמו עור וגידים"** - היום אומרים כך על **רעיון שמתחיל להתממש**.

## המילה המנחה: רוח

| פסוק | המשמעות |
|---|---|
| **1** | **"ויוציאני ברוח ה'"** - **השכינה**: הדרך של ה' **להעביר** את הנביא ממקום למקום |
| **5-6** | **"הנה אני מביא בכם רוח וחייתם"** - **חיים** |
| **8** | **"ורוח אין בהם"** - **נשמה**, חיים |
| **9** | **"מארבע רוחות"** - **כיווני השמיים**; וגם **משב אוויר** ממש |
| **10** | **"ותבוא בהם הרוח ויחיו"** - **נשמה** שנכנסת לגוף |
| **14** | **"ונתתי רוחי בכם"** - **רוח ה'** - כמו בבריאת האדם (**"ויפח באפיו נשמת חיים"**): **החיים באים מה'** |

## שאלות לחזרה

- מה ההבדל בין חזון למחזה?
- תאר את שלבי החזון.
- מה הנמשל של העצמות, היובש, הקברים והתחייה?
- מהן שתי הדרכים להבין את החזון?
- מה משמעויות המילה "רוח" בפרק?
