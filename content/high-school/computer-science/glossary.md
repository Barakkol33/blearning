# מילון מונחים (עברית-אנגלית)

רוב החומר על תכנות באינטרנט - **באנגלית**. כדאי להכיר את המונחים בשתי השפות.

## יסודות

| עברית | ‏English | הסבר קצר |
|---|---|---|
| משתנה | ‏variable | מקום בזיכרון עם שם, טיפוס וערך |
| טיפוס | ‏type | סוג הנתון: `int`, `double`, `char`, `string`, `bool` |
| הכרזה | ‏declaration | הגדרת משתנה: `int x;` |
| אתחול | ‏initialization | הצבת ערך ראשון |
| המרה | ‏casting / conversion | מעבר בין טיפוסים |
| קבוע | ‏constant | ערך שלא משתנה (`const`) |
| מזהה | ‏identifier | שם של משתנה, פעולה או מחלקה |
| מילה שמורה | ‏keyword | מילה של השפה: `if`, `class`, `return` |
| אופרטור | ‏operator | `+`, `==`, `&&`... |
| ביטוי בוליאני | ‏boolean expression | ביטוי שערכו אמת או שקר |
| לולאה | ‏loop | חזרה על קוד: `for`, `while` |
| מערך | ‏array | אוסף באורך קבוע מאותו טיפוס |
| אינדקס | ‏index | מיקום במערך, מ-0 |
| מחרוזת | ‏string | רצף תווים |
| תו | ‏character (char) | סימן בודד |
| פעולה | ‏method / function | קוד עם שם, פרמטרים וערך מוחזר |
| פרמטר | ‏parameter | ערך שפעולה מקבלת |
| ערך מוחזר | ‏return value | מה שהפעולה מחזירה |
| טווח הכרה | ‏scope | איפה בקוד המשתנה מוכר |
| טבלת מעקב | ‏trace table | מעקב ידני אחרי ערכי המשתנים |

## שגיאות

| עברית | ‏English |
|---|---|
| שגיאת תחביר (קומפילציה) | ‏syntax / compilation error |
| שגיאת זמן ריצה, חריגה | ‏runtime error, exception |
| שגיאה לוגית | ‏logic / semantic error |
| איתור באגים | ‏debugging |
| מהדר | ‏compiler |
| מפרש | ‏interpreter |

## מחלקות ועצמים

| עברית | ‏English | הסבר קצר |
|---|---|---|
| מחלקה | ‏class | תבנית לעצמים |
| עצם | ‏object / instance | מופע של מחלקה |
| תכונה | ‏field / attribute | נתון של עצם |
| פעולה בונה | ‏constructor | יוצרת עצם ומאתחלת אותו |
| פעולה מאחזרת / קובעת | ‏getter / setter | קוראת / משנה תכונה |
| מאפיין | ‏property | ‏`get`/`set` שנראים כמו תכונה |
| הפניה | ‏reference | "כתובת" של עצם |
| טיפוס ערך / הפניה | ‏value type / reference type | |
| אוסף זבל | ‏garbage collector | משחרר עצמים שאין אליהם הפניה |
| מחסנית / ערימה (זיכרון) | ‏stack / heap | |
| כימוס | ‏encapsulation | הסתרת המימוש מאחורי ממשק |
| הורשה | ‏inheritance | "סוג של" |
| מחלקת בסיס / נגזרת | ‏base / derived class | |
| פולימורפיזם | ‏polymorphism | קריאה וירטואלית לפי העצם בפועל |
| דריסה | ‏overriding | ‏`override` |
| העמסה | ‏overloading | אותו שם, פרמטרים שונים |
| מחלקה מופשטת | ‏abstract class | אי אפשר ליצור ממנה עצמים |
| ממשק | ‏interface | "חוזה" של חתימות |
| מחלקה גנרית | ‏generic class | ‏`Node<T>` - הטיפוס נקבע בשימוש |
