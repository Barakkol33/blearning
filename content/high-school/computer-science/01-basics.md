# יסודות: תכנית, משתנים, תנאים ולולאות, מערכים

הכלים הבסיסיים של כל תכנית: משתנים, תנאים, לולאות, מערכים, פעולות ומחרוזות.

## איך כותבים תכנית

לפני שכותבים שורת קוד, כדאי לעבור כמה שלבים. אצל מתכנתים מנוסים חלק מהם קורים כמעט אוטומטית. כשנתקעים - כדאי לבדוק שלא דילגנו על אחד מהם.

### השלבים

| שלב | מה עושים |
|---|---|
| **1. הבנת הדרישות** | מה התכנית צריכה **לקלוט**, **לחשב** ו**להדפיס**? (נשמע מובן מאליו - אבל כאן נופלים הכי הרבה) |
| **2. האלגוריתם** | מתכננים **בגדול** איך התכנית תפתור את הבעיה. לרוב אפשר לנסח את זה **בלי מחשב בכלל** - כמו שאדם היה עושה ביד |
| **3. חלוקה לפעולות** | מפרקים את התכנית ל**פעולות** (ו**מחלקות**) - שלכל אחת **אחריות אחת** והן **תלויות** זו בזו כמה שפחות |
| **4. כלי השפה** | מה צריך מהשפה: **לולאה**? **מערך**? **קלט של מספר**? **חיפוש תו במחרוזת**? |
| **5. כתיבת הקוד** | כותבים - עם **איות נכון**, **הזחות**, ו**שמות משמעותיים** |
| **6. בדיקה** | מריצים על **כמה קלטים** - כולל **מקרי קצה** - ומוודאים שהפלט נכון. על דף: **"מריצים בראש"** בטבלת מעקב |
| **7. תיעוד** | מסבירים את מה **שלא ברור מאליו** |

**למה לחלק לפעולות?** הקוד **קריא** יותר; קל **לבדוק** כל חלק לבד; אפשר **להחליף** חלק בלי לגעת בשאר; ואפשר **להשתמש שוב** בפעולה במקום אחר.

**טיפ**: הכינו לעצמכם **"דף כלי שפה"** - איך כותבים כל דבר שימושי (קלט, לולאה, מעבר על מערך, חיפוש במחרוזת...). בצורה: **"מה זה עושה: הקוד"**.

### דוגמה מלאה

**הדרישה**: תכנית שקולטת 100 מספרים ומדפיסה את **הממוצע** שלהם; אחר כך קולטת עוד 50 מספרים ומדפיסה את **הקטן ביותר**.

**האלגוריתם:**

- **ממוצע** - סוכמים את כל המספרים ומחלקים בכמות.
- **מינימום** - מניחים שהראשון הוא הקטן ביותר ושומרים אותו. עוברים על כל השאר: מספר קטן יותר מהשמור? שומרים אותו במקום. בסוף - השמור הוא הקטן ביותר. (בדיוק מה שאדם היה עושה.)

**החלוקה לפעולות:**

```csharp
static int[] ArrayInput(int size)   // reads `size` integers into a new array
static double Average(int[] arr)    // returns the average of the array
static int Min(int[] arr)           // returns the smallest value in the array
```

**הקוד:**

```csharp
class Program
{
    public static void Main(string[] args)
    {
        Console.WriteLine(Average(ArrayInput(100)));
        Console.WriteLine(Min(ArrayInput(50)));
    }

    // Reads `size` integers from the user and returns them in an array.
    public static int[] ArrayInput(int size)
    {
        int[] arr = new int[size];
        for (int i = 0; i < arr.Length; i++)
            arr[i] = int.Parse(Console.ReadLine());
        return arr;
    }

    // Returns the average of the numbers in arr.
    public static double Average(int[] arr)
    {
        double sum = 0;
        for (int i = 0; i < arr.Length; i++)
            sum += arr[i];
        return sum / arr.Length;
    }

    // Returns the smallest number in arr (assumes arr is not empty).
    public static int Min(int[] arr)
    {
        int min = arr[0];
        for (int i = 1; i < arr.Length; i++)
            if (arr[i] < min)
                min = arr[i];
        return min;
    }
}
```

שימו לב:

- ‏`sum` מוגדר כ-`double` - כדי שהחילוק **לא יעוגל** לשלם (ראו [משתנים וטיפוסים](#משתנים-טיפוסים-וטבלת-מעקב)).
- ‏`Min` מתחילה את הלולאה מ-`1` - האיבר הראשון כבר נבדק.
- כל פעולה **מתועדת** בשורה אחת: מה היא מקבלת ומה מחזירה.

## משתנים, טיפוסים וטבלת מעקב

### משתנים

**משתנה** - מקום בזיכרון עם **שם**, **טיפוס** ו**ערך**.

```csharp
int count = 0;          // declaration + initialization
double price = 9.90;
char grade = 'A';
string name = "Dana";
bool found = false;
```

**מתי לשים ערך במשתנה?** כשמשתמשים בו **יותר מפעם אחת**, או כשרוצים שיהיה **קל לשנות** אותו בלי לחפש בכל הקוד. אחרת - אפשר להשתמש בערך ישירות.

**שמות משמעותיים**: `sum`, `maxGrade` - לא `x`, `a1`. כדאי גם לכתוב בהערה **מה המשתנה מייצג**.

#### קבועים

```csharp
const int SIZE = 30;
```

ערך **שלא משתנה** - והקומפיילר **לא ירשה** לשנות אותו.

### טיפוסים בסיסיים

| טיפוס | מה | דוגמה |
|---|---|---|
| ‏`int` | מספר **שלם** (בטווח מוגבל: בערך ±2.1 מיליארד) | `-7`, `42` |
| ‏`long` | שלם **גדול** | |
| ‏`double` | מספר **ממשי** (עם נקודה עשרונית) | `3.14` |
| ‏`char` | **תו** בודד, בגרש | ‏`'a'`, `'7'` |
| ‏`string` | **מחרוזת**, במירכאות | ‏`"hello"` |
| ‏`bool` | **אמת או שקר** | ‏`true`, `false` |

### אופרטורים

| סוג | אופרטורים |
|---|---|
| **חשבון** | `+` `-` `*` `/` `%` |
| **השוואה** | `==` `!=` `<` `>` `<=` `>=` |
| **לוגיים** | `&&` (וגם), `\|‏\|` (או), `!` (לא) |
| **השמה מקוצרת** | `+=` `-=` `*=` `/=` `++` `--` |

#### חילוק ושארית - המלכודת הגדולה

- **חילוק בין שני שלמים** - התוצאה **שלמה** (החלק השברי **נחתך**): `7 / 2` הוא `3`.
- אם **אחד** מהם `double` - התוצאה ממשית: `7 / 2.0` הוא `3.5`.
- **שארית** - `7 % 2` הוא `1`. שימושים: **זוגיות** (`n % 2 == 0`), **ספרת האחדות** (`n % 10`), **הורדת ספרה** (`n / 10`).
- **שארית של מספר שלילי** - הסימן לפי **המחולק**: `-7 % 3` הוא `-1`. (הנוסחה: `a % n == a - (a / n) * n`.)

### המרות

```csharp
double d = 7;              // implicit: int -> double is safe
int i = (int)3.99;         // explicit cast: i == 3 (truncated, not rounded)
int n = int.Parse("42");   // string -> int
string s = n.ToString();   // int -> string
char c = (char)('a' + 1);  // c == 'b'
int code = (int)'A';       // code == 65
```

```csharp
int num = int.Parse(Console.ReadLine());      // read an integer
```


### מונה וצובר

- **מונה** - סופר **כמה** פעמים משהו קרה: `count++`.
- **צובר** - מחשב **סכום** (או מכפלה): `sum += x`.
- **חובה לאפס בהתחלה!** (ומכפלה - לאתחל ב-**1**.)
- **האתחול - מחוץ ללולאה!** אחרת הוא יתאפס בכל סיבוב.

### טבלת מעקב

**טבלת מעקב** - "מריצים את התכנית בראש" ורושמים את הערכים.

- **כל שורה** - שורת קוד, או **סיבוב** של לולאה, או **קריאה** לפעולה (ברקורסיה).
- **כל עמודה** - **משתנה**, **תנאי** (כולל תנאי הלולאה), **פלט**, או **ערך מוחזר**.
- **הפלט** - בדיוק כמו שהוא יודפס.
- לא חייבים לכתוב את החישובים - **רק את התוצאות**.
- **מריצים כמו המחשב** - שורה אחרי שורה, **בלי לדלג**. מי שמדלג "כי ברור מה זה עושה" - מפספס את הבאגים.

**דוגמה** - מה מדפיס הקוד?

```csharp
int n = 472, sum = 0;
while (n > 0)
{
    sum += n % 10;
    n /= 10;
}
Console.WriteLine(sum);
```

| ‏`n` | ‏`n > 0` | ‏`n % 10` | ‏`sum` | פלט |
|---|---|---|---|---|
| 472 | ‏true | 2 | 2 | |
| 47 | ‏true | 7 | 9 | |
| 4 | ‏true | 4 | 13 | |
| 0 | ‏false | | | `13` |

הקוד מחשב את **סכום הספרות**.

### שאלות לחזרה

- מה התוצאה של `9 / 4`, `9 / 4.0`, `9 % 4`, `(int)9.9`?
- איך מקבלים את ספרת העשרות של מספר?
- למה חשוב לאפס מונה **לפני** הלולאה ולא בתוכה?
- בנה טבלת מעקב לקוד שמחשב את מספר הספרות של מספר.


## תנאים ולולאות

### תנאים

```csharp
if (grade >= 90)
    Console.WriteLine("excellent");
else if (grade >= 55)
    Console.WriteLine("passed");
else
    Console.WriteLine("failed");
```

- **ביטוי בוליאני** - ביטוי שערכו `true` או `false`: `x > 0`, `a == b && c != d`.
- `&&` - **וגם**: נכון רק אם **שניהם** נכונים. `||` - **או**: נכון אם **לפחות אחד** נכון. `!` - **שלילה**.
- **הערכה מקוצרת**: ב-`a && b`, אם `a` שקר - `b` **לא נבדק**. שימושי: `i < arr.Length && arr[i] > 0` - הבדיקה הראשונה **מגינה** מחריגה מהמערך.
- **סוגריים מסולסלים** `{ }` - כשיש **יותר משורה אחת** בבלוק. בלעדיהם רק השורה **הראשונה** שייכת ל-`if`!
- **`==` מול `=`**: `==` **משווה**; `=` **מציב**.

#### ‏switch

כשבודקים **ערך אחד** מול הרבה אפשרויות:

```csharp
switch (day)
{
    case 1: Console.WriteLine("Sunday"); break;
    case 7: Console.WriteLine("Saturday"); break;
    default: Console.WriteLine("weekday"); break;
}
```

### לולאות

| לולאה | מתי | דוגמה |
|---|---|---|
| ‏`for` | **יודעים מראש** כמה סיבובים | מעבר על מערך |
| ‏`while` | חוזרים **כל עוד** תנאי מתקיים - **אולי אפס פעמים** | קליטה עד שמגיע `-1` |
| ‏`do-while` | כמו `while`, אבל **לפחות פעם אחת** (התנאי נבדק בסוף) | קליטה עם **בדיקת תקינות** |

```csharp
for (int i = 0; i < 10; i++)
    Console.WriteLine(i);           // 0..9

int x = int.Parse(Console.ReadLine());
while (x != -1)                     // sentinel loop
{
    sum += x;
    x = int.Parse(Console.ReadLine());
}

do
{
    age = int.Parse(Console.ReadLine());
} while (age < 0 || age > 120);     // repeat until the input is valid
```

**חלקי לולאת `for`**: **אתחול** (פעם אחת) ; **תנאי** (לפני כל סיבוב) ; **קידום** (אחרי כל סיבוב).

#### תבניות שחוזרות

| מה | איך |
|---|---|
| **מונה** | ‏`if (cond) count++;` |
| **צובר** | ‏`sum += x;` |
| **מקסימום/מינימום** | מתחילים **מהאיבר הראשון** (לא מ-0!), ומעדכנים כשמוצאים גדול/קטן יותר |
| **חיפוש** | משתנה `bool found = false;` - והלולאה **עוצרת** כשמוצאים: `while (i < n && !found)` |
| **פירוק לספרות** | ‏`while (n > 0) { digit = n % 10; n /= 10; }` |
| **"האם כולם..."** | מניחים `true`, ומחפשים **דוגמה נגדית** |

#### לולאות מקוננות

לולאה בתוך לולאה - הפנימית רצה **במלואה** בכל סיבוב של החיצונית. **מספר הפעולות**: מכפלת מספרי הסיבובים.

```csharp
for (int i = 1; i <= 3; i++)
{
    for (int j = 1; j <= i; j++)
        Console.Write("*");
    Console.WriteLine();
}
// *
// **
// ***
```

### טעויות נפוצות

- **לולאה אינסופית** - שוכחים לקדם את המשתנה ב-`while`.
- **"אחד יותר מדי"** - `<=` במקום `<` (או להפך).
- **`;` אחרי התנאי** - `if (x > 0);` - ה-`if` **ריק**, והשורה הבאה רצה תמיד.
- **אתחול בתוך הלולאה** - המשתנה חוזר לערכו בכל סיבוב.

- מתי משתמשים ב-`for`, ב-`while` וב-`do-while`?
- למה התנאי `i < arr.Length && arr[i] > 0` בטוח, אבל `arr[i] > 0 && i < arr.Length` לא?

## מערכים

### מערך חד-ממדי

**מערך** - אוסף של משתנים **מאותו טיפוס**, **באורך קבוע**, שממוספרים לפי **אינדקס** (מיקום) - **מ-0**.

```csharp
int[] grades = new int[30];        // 30 cells, all 0
int[] primes = { 2, 3, 5, 7 };     // initialized with values
grades[0] = 95;                    // first cell
int last = grades[grades.Length - 1];  // last cell
```

- **מאפיינים**: **שם**, **גודל**, **טיפוס**.
- **האינדקסים**: מ-`0` עד `Length - 1`.
- **אסור לגשת מחוץ למערך** - חריגה בזמן ריצה (`IndexOutOfRangeException`). **זהירות במיוחד** עם `arr[i + 1]` או `arr[i - 1]` בלולאה - צריך לעצור **אחד לפני** הסוף.
- **הגודל קבוע** - אי אפשר להגדיל מערך אחרי שנוצר.

#### מעבר על מערך

```csharp
for (int i = 0; i < arr.Length; i++)
    Console.WriteLine(arr[i]);
```

#### מערך מונים / צוברים

כשרוצים לספור **כמה פעמים** הופיע כל ערך (בטווח ידוע) - **האינדקס הוא הערך**:

```csharp
int[] count = new int[10];          // how many times each digit 0..9 appeared
while (n > 0)
{
    count[n % 10]++;
    n /= 10;
}
```

**לאפס** מערך מונים לפני השימוש (ב-C# `new` מאפס, אבל אם משתמשים בו שוב - צריך לולאת איפוס).

### מערך דו-ממדי

**טבלה** של שורות ועמודות:

```csharp
int[,] mat = new int[3, 4];        // 3 rows, 4 columns
mat[1, 2] = 7;                     // row 1, column 2
int rows = mat.GetLength(0);       // 3
int cols = mat.GetLength(1);       // 4
```

**מעבר** - **לולאות מקוננות**:

```csharp
for (int i = 0; i < mat.GetLength(0); i++)          // rows
    for (int j = 0; j < mat.GetLength(1); j++)      // columns
        sum += mat[i, j];
```

- **סכום שורה $i$** - לולאה **אחת** על $j$, עם $i$ קבוע.
- **סכום עמודה $j$** - לולאה **אחת** על $i$, עם $j$ קבוע.

#### מערך ריבועי - אלכסונים

![במערך ריבועי: האלכסון הראשי [i, i] והאלכסון המשני [i, N-1-i]](_files/array-2d.svg)

| | **אלכסון ראשי** | **אלכסון משני** |
|---|---|---|
| **האיברים** | ‏`a[i, i]` | ‏`a[i, N - 1 - i]` |
| **התנאי** | ‏`i == j` | ‏`i + j == N - 1` |
| **מעל האלכסון** | ‏`j > i` | ‏`i + j < N - 1` |

```csharp
for (int i = 0; i < N; i++)
    diagSum += a[i, i];             // one loop - no need for nested loops
```

### פעולות נפוצות על מערך

| פעולה | הרעיון |
|---|---|
| **סכום / ממוצע** | צובר |
| **מקסימום ומיקומו** | ‏`int maxIdx = 0;` ומשווים ל-`arr[maxIdx]` |
| **חיפוש ערך** | לולאה עם דגל `found` |
| **האם ממוין** | בודקים כל זוג **שכנים**: `arr[i] > arr[i + 1]` - עד `Length - 1` |
| **היפוך** | מחליפים `arr[i]` עם `arr[n - 1 - i]` - **רק עד האמצע** |
| **הזזה** | מזיזים איבר-איבר, **מהסוף** (בהזזה ימינה) כדי לא לדרוס |

**החלפת שני איברים** - צריך משתנה **עזר**:

```csharp
int temp = arr[i];
arr[i] = arr[j];
arr[j] = temp;
```
