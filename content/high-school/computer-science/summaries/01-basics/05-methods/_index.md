# פעולות

**פעולה** (מתודה, פונקציה) - קטע קוד **עם שם**, שמקבל **פרמטרים** ואולי **מחזיר ערך**. במקום לכתוב את אותו קוד שוב ושוב - **קוראים** לפעולה.

## המבנה

```csharp
public static int Add(int a, int b)   // access, static, return type, name, parameters
{
    return a + b;
}
```

```csharp
int s = Add(3, 4);                   // call: s == 7
```

| חלק | משמעות |
|---|---|
| ‏`public` / `private` | **מי** יכול לקרוא לפעולה |
| ‏`static` | שייכת **למחלקה**, לא לעצם (ראו [מחלקות](../../02-classes-and-algorithms/01-classes/_index.md)) |
| **טיפוס מוחזר** | ‏`int`, `bool`, `int[]`... או **`void`** - לא מחזירה כלום |
| **שם** | פועל משמעותי: `IsPrime`, `CountDigits` |
| **פרמטרים** | טיפוס ושם לכל אחד |

## ‏return

- פעולה שמחזירה ערך **חייבת** `return` - **בכל מסלול אפשרי** (כולל כל ענפי ה-`if`). אחרת - שגיאת קומפילציה.
- ‏`return` **מסיים** את הפעולה מיד.
- פעולת `void` - **בלי** ערך מוחזר (אפשר `return;` ריק כדי לצאת מוקדם).

```csharp
public static bool IsPrime(int n)
{
    if (n < 2)
        return false;
    for (int i = 2; i * i <= n; i++)
        if (n % i == 0)
            return false;      // found a divisor - stop
    return true;               // no divisor found
}
```

## פרמטרים

- בקריאה: **מספר**, **טיפוסים** ו**סדר** הפרמטרים חייבים להתאים להגדרה. **השמות** - לא.
- **העברה לפי ערך** (by value): הפעולה מקבלת **עותק**. שינוי פרמטר `int` בתוך הפעולה **לא משפיע** על המשתנה של הקורא.
- **אבל**: מערך ועצם - מה שמועתק הוא **ההפניה**. לכן שינוי **תוכן** המערך בתוך הפעולה **כן** משפיע על הקורא! (ראו [הפניות](../../02-classes-and-algorithms/02-references/_index.md).)

```csharp
static void Twice(int x)    { x *= 2; }      // caller's variable is unchanged
static void Clear(int[] a)  { a[0] = 0; }    // caller's array IS changed
```

## תיעוד פעולה

בשורה או שתיים מעל הפעולה:

- **מה היא מקבלת** (קלט) ו**מה מחזירה** (פלט).
- **הנחות** - למשל "המערך לא ריק", "n חיובי".
- **לא** לתאר את המימוש שורה אחרי שורה. כדאי להסביר רק שורות **מתוחכמות**.

## טיפים

- **השתמשו בפעולות שכבר כתבתם** - גם בשאלות הבאות בבחינה ("היעזרו בפעולה מסעיף א'").
- **ערך שצריך כמה פעמים** - שמרו במשתנה, ואל תקראו לפעולה שוב ושוב.
- בדקו שבכל קריאה **כל הפרמטרים** מועברים.

## שאלות לחזרה

- מה ההבדל בין פעולה `void` לפעולה שמחזירה ערך?
- למה הפעולה הבאה לא מתקמפלת? `static int Sign(int x) { if (x > 0) return 1; if (x < 0) return -1; }`
- מה ההבדל בין העברת `int` להעברת מערך לפעולה?
- כתוב פעולה שמקבלת מספר ומחזירה את מספר הספרות שלו.
