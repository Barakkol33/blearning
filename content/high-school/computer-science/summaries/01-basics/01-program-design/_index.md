# איך כותבים תכנית

לפני שכותבים שורת קוד, כדאי לעבור כמה שלבים. אצל מתכנתים מנוסים חלק מהם קורים כמעט אוטומטית. כשנתקעים - כדאי לבדוק שלא דילגנו על אחד מהם.

## השלבים

| שלב | מה עושים |
|---|---|
| **1. הבנת הדרישות** | מה התכנית צריכה **לקלוט**, **לחשב** ו**להדפיס**? (נשמע מובן מאליו - אבל כאן נופלים הכי הרבה) |
| **2. האלגוריתם** | מתכננים **בגדול** איך התכנית תפתור את הבעיה. לרוב אפשר לנסח את זה **בלי מחשב בכלל** - כמו שאדם היה עושה ביד |
| **3. חלוקה לפעולות** | מפרקים את התכנית ל**פעולות** (ו**מחלקות**) - שלכל אחת **אחריות אחת** והן **תלויות** זו בזו כמה שפחות |
| **4. כלי השפה** | מה צריך מהשפה: **לולאה**? **מערך**? **קלט של מספר**? **חיפוש תו במחרוזת**? |
| **5. כתיבת הקוד** | כותבים - עם **איות נכון**, **הזחות**, ו**שמות משמעותיים** |
| **6. בדיקה** | מריצים על **כמה קלטים** - כולל **מקרי קצה** - ומוודאים שהפלט נכון. על דף: **"מריצים בראש"** בטבלת מעקב |
| **7. תיעוד** | מסבירים את מה **שלא ברור מאליו** |

**למה לחלק לפעולות?** הקוד **קריא** יותר; קל **לבדוק** כל חלק לבד; אפשר **להחליף** חלק בלי לגעת בשאר; ואפשר **להשתמש שוב** בפעולה במקום אחר.

**טיפ**: הכינו לעצמכם **"דף כלי שפה"** - איך כותבים כל דבר שימושי (קלט, לולאה, מעבר על מערך, חיפוש במחרוזת...). בצורה: **"מה זה עושה: הקוד"**.

## דוגמה מלאה

**הדרישה**: תכנית שקולטת 100 מספרים ומדפיסה את **הממוצע** שלהם; אחר כך קולטת עוד 50 מספרים ומדפיסה את **הקטן ביותר**.

**האלגוריתם:**

- **ממוצע** - סוכמים את כל המספרים ומחלקים בכמות.
- **מינימום** - מניחים שהראשון הוא הקטן ביותר ושומרים אותו. עוברים על כל השאר: מספר קטן יותר מהשמור? שומרים אותו במקום. בסוף - השמור הוא הקטן ביותר. (בדיוק מה שאדם היה עושה.)

**החלוקה לפעולות:**

```csharp
static int[] ArrayInput(int size)   // reads `size` integers into a new array
static double Average(int[] arr)    // returns the average of the array
static int Min(int[] arr)           // returns the smallest value in the array
```

**הקוד:**

```csharp
class Program
{
    public static void Main(string[] args)
    {
        Console.WriteLine(Average(ArrayInput(100)));
        Console.WriteLine(Min(ArrayInput(50)));
    }

    // Reads `size` integers from the user and returns them in an array.
    public static int[] ArrayInput(int size)
    {
        int[] arr = new int[size];
        for (int i = 0; i < arr.Length; i++)
            arr[i] = int.Parse(Console.ReadLine());
        return arr;
    }

    // Returns the average of the numbers in arr.
    public static double Average(int[] arr)
    {
        double sum = 0;
        for (int i = 0; i < arr.Length; i++)
            sum += arr[i];
        return sum / arr.Length;
    }

    // Returns the smallest number in arr (assumes arr is not empty).
    public static int Min(int[] arr)
    {
        int min = arr[0];
        for (int i = 1; i < arr.Length; i++)
            if (arr[i] < min)
                min = arr[i];
        return min;
    }
}
```

שימו לב:

- ‏`sum` מוגדר כ-`double` - כדי שהחילוק **לא יעוגל** לשלם (ראו [משתנים וטיפוסים](../02-variables-and-types/_index.md)).
- ‏`Min` מתחילה את הלולאה מ-`1` - האיבר הראשון כבר נבדק.
- כל פעולה **מתועדת** בשורה אחת: מה היא מקבלת ומה מחזירה.
