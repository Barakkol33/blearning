# תנאים ולולאות

## תנאים

```csharp
if (grade >= 90)
    Console.WriteLine("excellent");
else if (grade >= 55)
    Console.WriteLine("passed");
else
    Console.WriteLine("failed");
```

- **ביטוי בוליאני** - ביטוי שערכו `true` או `false`: `x > 0`, `a == b && c != d`.
- `&&` - **וגם**: נכון רק אם **שניהם** נכונים. `||` - **או**: נכון אם **לפחות אחד** נכון. `!` - **שלילה**.
- **הערכה מקוצרת**: ב-`a && b`, אם `a` שקר - `b` **לא נבדק**. שימושי: `i < arr.Length && arr[i] > 0` - הבדיקה הראשונה **מגינה** מחריגה מהמערך.
- **סוגריים מסולסלים** `{ }` - כשיש **יותר משורה אחת** בבלוק. בלעדיהם רק השורה **הראשונה** שייכת ל-`if`!
- **`==` מול `=`**: `==` **משווה**; `=` **מציב**.

### ‏switch

כשבודקים **ערך אחד** מול הרבה אפשרויות:

```csharp
switch (day)
{
    case 1: Console.WriteLine("Sunday"); break;
    case 7: Console.WriteLine("Saturday"); break;
    default: Console.WriteLine("weekday"); break;
}
```

## לולאות

| לולאה | מתי | דוגמה |
|---|---|---|
| ‏`for` | **יודעים מראש** כמה סיבובים | מעבר על מערך |
| ‏`while` | חוזרים **כל עוד** תנאי מתקיים - **אולי אפס פעמים** | קליטה עד שמגיע `-1` |
| ‏`do-while` | כמו `while`, אבל **לפחות פעם אחת** (התנאי נבדק בסוף) | קליטה עם **בדיקת תקינות** |

```csharp
for (int i = 0; i < 10; i++)
    Console.WriteLine(i);           // 0..9

int x = int.Parse(Console.ReadLine());
while (x != -1)                     // sentinel loop
{
    sum += x;
    x = int.Parse(Console.ReadLine());
}

do
{
    age = int.Parse(Console.ReadLine());
} while (age < 0 || age > 120);     // repeat until the input is valid
```

**חלקי לולאת `for`**: **אתחול** (פעם אחת) ; **תנאי** (לפני כל סיבוב) ; **קידום** (אחרי כל סיבוב).

### תבניות שחוזרות

| מה | איך |
|---|---|
| **מונה** | ‏`if (cond) count++;` |
| **צובר** | ‏`sum += x;` |
| **מקסימום/מינימום** | מתחילים **מהאיבר הראשון** (לא מ-0!), ומעדכנים כשמוצאים גדול/קטן יותר |
| **חיפוש** | משתנה `bool found = false;` - והלולאה **עוצרת** כשמוצאים: `while (i < n && !found)` |
| **פירוק לספרות** | ‏`while (n > 0) { digit = n % 10; n /= 10; }` |
| **"האם כולם..."** | מניחים `true`, ומחפשים **דוגמה נגדית** |

### לולאות מקוננות

לולאה בתוך לולאה - הפנימית רצה **במלואה** בכל סיבוב של החיצונית. **מספר הפעולות**: מכפלת מספרי הסיבובים.

```csharp
for (int i = 1; i <= 3; i++)
{
    for (int j = 1; j <= i; j++)
        Console.Write("*");
    Console.WriteLine();
}
// *
// **
// ***
```

## טעויות נפוצות

- **לולאה אינסופית** - שוכחים לקדם את המשתנה ב-`while`.
- **"אחד יותר מדי"** - `<=` במקום `<` (או להפך).
- **`;` אחרי התנאי** - `if (x > 0);` - ה-`if` **ריק**, והשורה הבאה רצה תמיד.
- **אתחול בתוך הלולאה** - המשתנה חוזר לערכו בכל סיבוב.
