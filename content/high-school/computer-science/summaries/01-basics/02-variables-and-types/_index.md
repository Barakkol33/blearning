# משתנים, טיפוסים וטבלת מעקב

## משתנים

**משתנה** - מקום בזיכרון עם **שם**, **טיפוס** ו**ערך**.

```csharp
int count = 0;          // declaration + initialization
double price = 9.90;
char grade = 'A';
string name = "Dana";
bool found = false;
```

**מתי לשים ערך במשתנה?** כשמשתמשים בו **יותר מפעם אחת**, או כשרוצים שיהיה **קל לשנות** אותו בלי לחפש בכל הקוד. אחרת - אפשר להשתמש בערך ישירות.

**שמות משמעותיים**: `sum`, `maxGrade` - לא `x`, `a1`. כדאי גם לכתוב בהערה **מה המשתנה מייצג**.

### קבועים

```csharp
const int SIZE = 30;
```

ערך **שלא משתנה** - והקומפיילר **לא ירשה** לשנות אותו.

## טיפוסים בסיסיים

| טיפוס | מה | דוגמה |
|---|---|---|
| ‏`int` | מספר **שלם** (בטווח מוגבל: בערך ±2.1 מיליארד) | `-7`, `42` |
| ‏`long` | שלם **גדול** | |
| ‏`double` | מספר **ממשי** (עם נקודה עשרונית) | `3.14` |
| ‏`char` | **תו** בודד, בגרש | ‏`'a'`, `'7'` |
| ‏`string` | **מחרוזת**, במירכאות | ‏`"hello"` |
| ‏`bool` | **אמת או שקר** | ‏`true`, `false` |

### חילוק ושארית - המלכודת הגדולה

- **חילוק בין שני שלמים** - התוצאה **שלמה** (החלק השברי **נחתך**): `7 / 2` הוא `3`.
- אם **אחד** מהם `double` - התוצאה ממשית: `7 / 2.0` הוא `3.5`.
- **שארית** - `7 % 2` הוא `1`. שימושים: **זוגיות** (`n % 2 == 0`), **ספרת האחדות** (`n % 10`), **הורדת ספרה** (`n / 10`).
- **שארית של מספר שלילי** - הסימן לפי **המחולק**: `-7 % 3` הוא `-1`. (הנוסחה: `a % n == a - (a / n) * n`.)

## המרות

```csharp
double d = 7;              // implicit: int -> double is safe
int i = (int)3.99;         // explicit cast: i == 3 (truncated, not rounded)
int n = int.Parse("42");   // string -> int
string s = n.ToString();   // int -> string
char c = (char)('a' + 1);  // c == 'b'
int code = (int)'A';       // code == 65
```

## מונה וצובר

- **מונה** - סופר **כמה** פעמים משהו קרה: `count++`.
- **צובר** - מחשב **סכום** (או מכפלה): `sum += x`.
- **חובה לאפס בהתחלה!** (ומכפלה - לאתחל ב-**1**.)
- **האתחול - מחוץ ללולאה!** אחרת הוא יתאפס בכל סיבוב.

## טבלת מעקב

**טבלת מעקב** - "מריצים את התכנית בראש" ורושמים את הערכים.

- **כל שורה** - שורת קוד, או **סיבוב** של לולאה, או **קריאה** לפעולה (ברקורסיה).
- **כל עמודה** - **משתנה**, **תנאי** (כולל תנאי הלולאה), **פלט**, או **ערך מוחזר**.
- **הפלט** - בדיוק כמו שהוא יודפס.
- לא חייבים לכתוב את החישובים - **רק את התוצאות**.
- **מריצים כמו המחשב** - שורה אחרי שורה, **בלי לדלג**. מי שמדלג "כי ברור מה זה עושה" - מפספס את הבאגים.

**דוגמה** - מה מדפיס הקוד?

```csharp
int n = 472, sum = 0;
while (n > 0)
{
    sum += n % 10;
    n /= 10;
}
Console.WriteLine(sum);
```

| ‏`n` | ‏`n > 0` | ‏`n % 10` | ‏`sum` | פלט |
|---|---|---|---|---|
| 472 | ‏true | 2 | 2 | |
| 47 | ‏true | 7 | 9 | |
| 4 | ‏true | 4 | 13 | |
| 0 | ‏false | | | `13` |

הקוד מחשב את **סכום הספרות**.

## שאלות לחזרה

- מה התוצאה של `9 / 4`, `9 / 4.0`, `9 % 4`, `(int)9.9`?
- איך מקבלים את ספרת העשרות של מספר?
- למה חשוב לאפס מונה **לפני** הלולאה ולא בתוכה?
- בנה טבלת מעקב לקוד שמחשב את מספר הספרות של מספר.
