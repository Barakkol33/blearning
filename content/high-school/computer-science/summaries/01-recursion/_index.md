# רקורסיה

פעולה רקורסיבית פותרת בעיה בעזרת אותה בעיה בגודל קטן יותר. תמיד צריך **תנאי עצירה**.

```csharp
public static int Factorial(int n)
{
    if (n <= 1) return 1;          // תנאי עצירה
    return n * Factorial(n - 1);   // צעד רקורסיבי
}
```

כל קריאה נשמרת במחסנית הקריאות עד שהיא מסתיימת. בלי תנאי עצירה המחסנית מתמלאת (StackOverflow).
