# מדעי המחשב

מדעי המחשב לבגרות, בשפת **C#**, בארבעה חלקים:

1. **יסודות** - משתנים, תנאים, לולאות, מערכים, פעולות ומחרוזות.
2. **מחלקות ואלגוריתמים** - מחלקות ועצמים, הפניות, רקורסיה ויעילות.
3. **מבני נתונים** - שרשרת חוליות, מחסנית, תור ועץ בינארי.
4. **תכנות מונחה עצמים** - כימוס, הורשה, פולימורפיזם ותרשימי UML.

## איך ללמוד

- **לתכנת**: אי אפשר ללמוד לתכנת רק מקריאה. כתבו והריצו את הדוגמאות, ושנו אותן.
- **טבלאות מעקב**: תרגלו "הרצה בראש" - זה חלק גדול מהבחינה.
- **דף כלי שפה**: רשמו לעצמכם איך כותבים כל דבר שימושי (ראו [איך כותבים תכנית](01-basics.md#איך-כותבים-תכנית)).

## חומר עזר מותר לשימוש

- ללא חומר עזר.

בבחינה מצורף בדרך כלל **ממשק המחלקות** של מבני הנתונים (`Node<T>`, `Stack<T>`, `Queue<T>`, `BinNode<T>`) - כדאי להכיר אותו מראש.

## דגשים לבחינה

### כתיבת קוד

- **לכתוב נקי, מסודר וקריא** - עם **הזחות** נכונות.
- **לענות רק על מה ששאלו.**
- **`;`** בסוף כל הוראה, ו**סוגריים** ו**בלוקים** `{ }` שנסגרים נכון.
- **שמות משמעותיים** למשתנים ולפעולות. אחרי הכרזה - כדאי לכתוב **מה המשתנה מייצג**.
- **לאפס מונים וצוברים** בהתחלה - גם **מערכי** מונים וצוברים.
- **לא לחרוג מגבולות מערך** - במיוחד עם `arr[i + 1]`.
- פעולה שמחזירה ערך - **`return` בכל מסלול**. פעולת `void` - בלי.
- ערך שצריך **כמה פעמים** - לשמור **במשתנה**.
- בכל קריאה לפעולה - לבדוק ש**כל הפרמטרים** מועברים, בסדר הנכון.

### בדיקה

- **השאלה נותנת דוגמה?** בדקו עליה את הפתרון **בטבלת מעקב**. הדוגמה בדרך כלל כוללת את **מקרי הקצה**.

### תיעוד

- **פעולה**: מה היא **מקבלת**, מה **מחזירה**, ואילו **הנחות** היא עושה. **לא** לתאר את המימוש. מותר בשפה חופשית.
- **תכנית**: מה **הקלט** ומה **הפלט**.
- **מחלקה**: **כותרת**, **תכונות** ו**פעולות**.
- **שורות מתוחכמות** - להסביר.

### יעילות

- **לא לכתוב "תבניתית"** - לחשוב על הפתרון היעיל ביותר (לפעמים מעבר **אחד** מספיק).
- בניתוח: **סדר גודל**, **מה $n$**, ו**נימוק** (ראו [יעילות](03-classes-and-algorithms.md#יעילות-חיפוש-ומיון)).

### הפניות

- השוואה או השמה של **עצמים** (לא `int`, `bool`...) **לא יוצרת עותק** - רק מעתיקה או משווה **הפניות** (ראו [הפניות](03-classes-and-algorithms.md#הפניות-ועצמים-מורכבים)).

### מילים בשאלה שרומזות על הכלי

| ניסוח בשאלה | הכלי |
|---|---|
| "**מספר** ה..." | **מונה** |
| "**סכום**", "סך הכול" | **צובר** |
| "**אם**", "**אחרת**" | ‏`if`, `else` |
| "**עבור** כל", "**כל עוד**" | ‏`for`, `while` |
| "פעולה ש**מחזירה**" | ‏`return` |
| "**מחלקה**" | ‏`class` |
| "פעולה **מאחזרת**" | ‏`Get...` |
| "פעולה **קובעת**" | ‏`Set...` |

## מילון מונחים (עברית-אנגלית)

רוב החומר על תכנות באינטרנט - **באנגלית**. כדאי להכיר את המונחים בשתי השפות.

### יסודות

| עברית | ‏English | הסבר קצר |
|---|---|---|
| משתנה | ‏variable | מקום בזיכרון עם שם, טיפוס וערך |
| טיפוס | ‏type | סוג הנתון: `int`, `double`, `char`, `string`, `bool` |
| הכרזה | ‏declaration | הגדרת משתנה: `int x;` |
| אתחול | ‏initialization | הצבת ערך ראשון |
| המרה | ‏casting / conversion | מעבר בין טיפוסים |
| קבוע | ‏constant | ערך שלא משתנה (`const`) |
| מזהה | ‏identifier | שם של משתנה, פעולה או מחלקה |
| מילה שמורה | ‏keyword | מילה של השפה: `if`, `class`, `return` |
| אופרטור | ‏operator | `+`, `==`, `&&`... |
| ביטוי בוליאני | ‏boolean expression | ביטוי שערכו אמת או שקר |
| לולאה | ‏loop | חזרה על קוד: `for`, `while` |
| מערך | ‏array | אוסף באורך קבוע מאותו טיפוס |
| אינדקס | ‏index | מיקום במערך, מ-0 |
| מחרוזת | ‏string | רצף תווים |
| תו | ‏character (char) | סימן בודד |
| פעולה | ‏method / function | קוד עם שם, פרמטרים וערך מוחזר |
| פרמטר | ‏parameter | ערך שפעולה מקבלת |
| ערך מוחזר | ‏return value | מה שהפעולה מחזירה |
| טווח הכרה | ‏scope | איפה בקוד המשתנה מוכר |
| טבלת מעקב | ‏trace table | מעקב ידני אחרי ערכי המשתנים |
