# מונחים בסיסיים

- **וקטור**: גודל שיש לו כיוון וגודל.
- **מכפלה סקלרית**: u·v = |u||v|cos θ; שווה 0 כשהווקטורים מאונכים.
- **מספר מרוכב**: מספר מהצורה a+bi, כאשר i² = -1.
- **e**: הבסיס הטבעי, בערך 2.718; הנגזרת של eˣ היא eˣ.
- **לוגריתם**: log_a(b) = c אם ורק אם aᶜ = b.
