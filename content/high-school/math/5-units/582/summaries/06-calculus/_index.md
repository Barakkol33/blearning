# חשבון דיפרנציאלי ואינטגרלי - הרחבה

בשאלון 582 משתמשים בכל הכלים של [חדו"א בשאלון 581](../../../581/summaries/04-calculus/_index.md) - חקירה, בעיות קיצון, שטחים ונפחים - גם על **פונקציות מעריכיות, לוגריתמיות** ו**חזקות עם מעריך רציונלי**.

## נגזרות ואינטגרלים חדשים

| פונקציה | נגזרת | אינטגרל |
|---|---|---|
| ‏$e^x$ | ‏$e^x$ | ‏$e^x + C$ |
| ‏$a^x$ | ‏$a^x\ln a$ | ‏$\frac{a^x}{\ln a} + C$ |
| ‏$\ln x$ | ‏$\frac{1}{x}$ | ‏$x\ln x - x + C$ (צריך להוכיח - גוזרים) |
| ‏$\log_a x$ | ‏$\frac{1}{x\ln a}$ | |
| ‏$\frac{1}{x}$ | | ‏$\ln\lvert x\rvert + C$ |

**עם פונקציה פנימית** (כלל השרשרת):

- ‏$\left[e^{f(x)}\right]' = e^{f(x)}f'(x)$. למשל $\left(e^{x^2}\right)' = 2xe^{x^2}$.
- ‏$\left[\ln f(x)\right]' = \frac{f'(x)}{f(x)}$.
- **ולהפך** - אינטגרל חשוב:
$$\int\frac{f'(x)}{f(x)}\,dx = \ln\lvert f(x)\rvert + C$$
  (**ערך מוחלט** - כי $f$ יכולה להיות שלילית.) למשל $\int\frac{2x}{x^2 + 1}\,dx = \ln(x^2 + 1) + C$.
- **בלוג בבסיס אחר** - $\ln a$ במכנה **יכול להפוך את הסימן** (אם $a < 1$, $\ln a < 0$).

## תחום הגדרה

| פונקציה | תחום |
|---|---|
| **מעריכית** $a^{f(x)}$ | כמו של $f$ (בדרך כלל **כל $x$**) |
| **לוגריתמית** $\log f(x)$ | ‏$f(x) > 0$ |
| **שורש זוגי** $\sqrt[n]{f(x)}$, $n$ זוגי | ‏$f(x) \ge 0$ |
| **שורש אי-זוגי** | **כל** $x$ |
| **חזקה רציונלית** $x^{m/n}$ | ‏$x \ge 0$ (כשכותבים בצורת חזקה) |

## קיצון "חוד"

**נקודת חוד** - הנגזרת **לא מוגדרת** שם, אבל **מחליפה סימן** - ולכן זו **נקודת קיצון**. דוגמה: $y = \sqrt[3]{x^2}$ ב-$x = 0$ (מינימום). (אם הנגזרת לא מוגדרת **ולא** מחליפה סימן - זו נקודה עם **משיק אנכי**, כמו $\sqrt[3]{x}$.)

**בטבלת הערכים** - מכניסים גם את הנקודות שבהן **הנגזרת לא מוגדרת**.

## גבולות עם $e^x$ ו-$\ln x$

כדי לגלות **אסימפטוטות** ו**חורים**, מציבים ערכים **שמתקרבים** לנקודה (משני הצדדים) ובודקים לאן הפונקציה הולכת. **כדאי לזכור:**

- ‏$e^x \to 0$ כש-$x \to -\infty$; $e^x \to \infty$ כש-$x \to \infty$.
- ‏$\ln x \to -\infty$ כש-$x \to 0^+$.
- ‏**$e^x$ "מנצח" כל חזקה**: $\frac{x^n}{e^x} \to 0$ כש-$x \to \infty$. **כל חזקה "מנצחת" את $\ln x$**: $\frac{\ln x}{x} \to 0$.

**דוגמה**: $f(x) = xe^{1/x}$ ב-$x = 0$:

- **מימין** ($x \to 0^+$): $\frac{1}{x} \to \infty$, ו-$e^{1/x}$ גדל **הרבה יותר מהר** מש-$x$ קטן ⟹ $f \to \infty$: **אסימפטוטה אנכית**.
- **משמאל** ($x \to 0^-$): $\frac{1}{x} \to -\infty$ ⟹ $e^{1/x} \to 0$ ⟹ $f \to 0$: הגרף **מתקרב לראשית** (בלי להגיע).

## שאלות לחזרה

- גזור: $x^2e^{-x}$, $\ln(x^2 + 4)$, $2^{3x}$.
- חשב: $\int e^{2x}\,dx$, $\int\frac{3}{3x + 1}\,dx$, $\int_1^e\frac{\ln x}{x}\,dx$.
- הוכח ש-$\int\ln x\,dx = x\ln x - x + C$.
- מצא את תחום ההגדרה של $\ln(4 - x^2)$.
- האם ל-$\sqrt[3]{x^2}$ יש קיצון ב-$x = 0$? הסבר.
