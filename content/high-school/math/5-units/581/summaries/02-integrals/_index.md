# אינטגרלים

אינטגרל הוא הפעולה ההפוכה לגזירה, וגם השטח שמתחת לגרף:

$$\int_a^b f(x)\,dx = F(b) - F(a)$$

**דוגמה:** השטח שמתחת ל-$y = x^2$ בין 0 ל-3:

$$\int_0^3 x^2\,dx = \left[\tfrac{x^3}{3}\right]_0^3 = 9$$

**שימו לב:** שטח שמתחת לציר x יוצא שלילי באינטגרל. כשמחשבים שטח, מפצלים את התחום בנקודות החיתוך.
