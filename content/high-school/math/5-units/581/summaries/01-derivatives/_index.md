# נגזרות וחקירה

הנגזרת $f'(x)$ מודדת כמה מהר הפונקציה משתנה. כלל החזקה:

$$(x^n)' = n x^{n-1}$$

**חקירת פונקציה:**

1. תחום הגדרה.
2. נקודות חיתוך עם הצירים.
3. נגזרת, ופתרון $f'(x) = 0$ כדי למצוא נקודות קיצון.
4. תחומי עלייה וירידה לפי סימן הנגזרת.

**דוגמה:** $f(x) = x^3 - 3x$, ולכן $f'(x) = 3x^2 - 3 = 0$, כלומר $x = \pm 1$. מקסימום ב-$(-1, 2)$ ומינימום ב-$(1, -2)$.
