# אלגברה

## מספרים וביטויים אלגבריים

### קבוצות של מספרים

| קבוצה | סימון | מה בה | דוגמאות |
|---|---|---|---|
| **טבעיים** | ‏$\mathbb{N}$ | שלמים **חיוביים** | ‏$1, 5, 100$ |
| **שלמים** | ‏$\mathbb{Z}$ | שלמים חיוביים, **שליליים** ו**אפס** | ‏$0, -3$ |
| **רציונליים** | ‏$\mathbb{Q}$ | מספרים שאפשר לכתוב כ**מנה של שני שלמים** (המכנה שונה מ-0) | ‏$\frac{1}{9}$, $0.123$, $-4$ |
| **אי-רציונליים** | | כל השאר: שבר עשרוני **אינסופי ולא מחזורי** | ‏$\sqrt{2}$, $\pi$, $e$ |
| **ממשיים** | ‏$\mathbb{R}$ | הרציונליים **והאי-רציונליים** יחד - כל הנקודות על ציר המספרים | |
| **מרוכבים** | ‏$\mathbb{C}$ | מהצורה $a + bi$ (בשאלון 582) | ‏$3 + 2i$ |

כל קבוצה **מוכלת** בבאה: $\mathbb{N} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R} \subset \mathbb{C}$.

### חוקי החשבון

- **חוק החילוף**: $a + b = b + a$, $ab = ba$.
- **חוק הקיבוץ**: $(a + b) + c = a + (b + c)$ - בחיבור ובכפל אפשר לשים סוגריים איפה שרוצים.
- **חוק הפילוג** (פתיחת סוגריים): $a(b + c) = ab + ac$. **מורחב**: $(a + b)(c + d) = ac + ad + bc + bd$.
- **ערך מוחלט** - המרחק מאפס: $|-3| = |3| = 3$.

### שברים ואחוזים

- **צמצום** - רק **מכפלות**! $\frac{2x}{2y} = \frac{x}{y}$, אבל $\frac{x + 2}{y + 2} \neq \frac{x}{y}$.
- **חילוק שבר במספר**: $\frac{a}{b} \div c = \frac{a}{bc}$.
- **חילוק שבר בשבר** - כפל בהופכי: $\frac{a}{b} \div \frac{c}{d} = \frac{ad}{bc}$.
- **מכנה משותף** - מחפשים את **הכפולה הקטנה ביותר** המשותפת. דרך אחת: לוקחים את הגדול ובודקים את כפולותיו (ל-$2, 3, 7$: $7, 14, \ldots, 42$). דרך שנייה: מפרקים כל מספר **לגורמים ראשוניים** ולוקחים את כל הגורמים.
- **כל מספר טבעי** אפשר לכתוב כ**מכפלה של ראשוניים** - ובדרך אחת בלבד.
- **אחוזים** - **שיטת משולש**: $\frac{\text{חדש}}{\text{מקורי}} = \frac{\text{אחוז חדש}}{100}$. **עלייה** של 20% = **כפל ב-1.2**; **ירידה** של 20% = **כפל ב-0.8**.

### חזקות

‏$a^n$ - $a$ הוא **הבסיס**, $n$ - **המעריך**.

| | | |
|---|---|---|
| ‏$a^1 = a$ | ‏$a^n \cdot a^m = a^{n+m}$ | ‏$(a^n)^m = a^{nm}$ |
| ‏$a^0 = 1$ | ‏$\frac{a^n}{a^m} = a^{n-m}$ | ‏$(ab)^n = a^n b^n$ |
| ‏$a^{-n} = \frac{1}{a^n}$ | | ‏$\left(\frac{a}{b}\right)^n = \frac{a^n}{b^n}$ |

**טעות נפוצה**: $(a + b)^n \neq a^n + b^n$. החזקה **לא מתפלגת** על חיבור!

### שורשים

$$\sqrt[n]{ab} = \sqrt[n]{a}\,\sqrt[n]{b} \qquad \sqrt[n]{\frac{a}{b}} = \frac{\sqrt[n]{a}}{\sqrt[n]{b}} \qquad \sqrt[n]{a^m} = a^{m/n}$$

- **שורש של ריבוע**: $\sqrt{b^2} = |b|$ - **לא** $b$! לכן כשמוציאים שורש ממשוואה - **שתי תוצאות**: $x^2 = 9 \Rightarrow x = \pm 3$.
- **הוצאת שורש מהמכנה**: $\frac{1}{\sqrt{x}} = \frac{\sqrt{x}}{x}$.

### פירוק לגורמים

**פירוק לגורמים** - כתיבת ביטוי כ**מכפלה**. שימושי לצמצום, לפתרון משוואות ולמציאת סימן.

| שיטה | דוגמה |
|---|---|
| **הוצאת גורם משותף** | ‏$ax + bx = x(a + b)$ |
| **פירוק לפי קבוצות** | ‏$ax + bx + an + bn = x(a + b) + n(a + b) = (a + b)(x + n)$ |
| **נוסחאות הכפל המקוצר** | ראו בטבלה |
| **טרינום** | ‏$x^2 + 5x + 6 = (x + 2)(x + 3)$ |

**נוסחאות הכפל המקוצר:**

| | |
|---|---|
| ‏$(a \pm b)^2 = a^2 \pm 2ab + b^2$ | ‏$(a \pm b)^3 = a^3 \pm 3a^2b + 3ab^2 \pm b^3$ |
| ‏$a^2 - b^2 = (a + b)(a - b)$ | ‏$a^3 \pm b^3 = (a \pm b)(a^2 \mp ab + b^2)$ |

**פירוק טרינום** $x^2 + bx + c$: מחפשים שני מספרים $s, u$ ש**מכפלתם** $c$ ו**סכומם** $b$, ואז $x^2 + bx + c = (x + s)(x + u)$. מתחילים **מהמכפלה** - יש לה פחות אפשרויות.

**טרינום עם מקדם** $ax^2 + bx + c$: אם השורשים הם $x_1, x_2$ (מנוסחת השורשים), אז $ax^2 + bx + c = a(x - x_1)(x - x_2)$.

### שברים אלגבריים

**חיבור וצמצום** - הסדר:

1. **פירוק המכנים** לגורמים, ו**קבוצת הצבה** (המכנים $\neq 0$) - **לפני** שמצמצמים!
2. **מכנה משותף** מינימלי והרחבה.
3. **חיבור/חיסור** ופישוט.
4. **פירוק** המונה ו**צמצום**.

**משוואה עם שברים**: קבוצת הצבה ← הכפלה במכנה המשותף ← פתרון ← **בדיקה** מול קבוצת ההצבה. פתרון שסותר אותה - **"נפסל, סותר את קבוצת ההצבה"**.

**דוגמה**: $\frac{x^2 - 4}{x^2 - 2x} = \frac{(x - 2)(x + 2)}{x(x - 2)} = \frac{x + 2}{x}$, עם קבוצת הצבה $x \neq 0, 2$ - **גם אחרי** שה-$(x - 2)$ צומצם.

### שאלות לחזרה

- האם $0.333\ldots$ רציונלי? ו-$\sqrt{9}$?
- פרק לגורמים: $x^3 - 8$, $2x^2 - 8$, $x^2 - x - 12$.
- למה $\sqrt{x^2}$ אינו תמיד $x$?
- מחיר עלה ב-10% ואחר כך ירד ב-10%. האם חזר למקורי?

## משוואות ואי-שוויונים

### מה מותר לעשות לשני האגפים?

| פעולה | במשוואה | באי-שוויון |
|---|---|---|
| **חיבור / חיסור** | מותר | מותר |
| **כפל / חילוק במספר חיובי** | מותר | מותר |
| **כפל / חילוק במספר שלילי** | מותר | **הופך את כיוון** אי-השוויון |
| **חילוק בביטוי** | רק אם הוא **$\neq 0$** - ואת המקרה $= 0$ **בודקים בנפרד** | צריך לדעת את **הסימן** שלו |
| **כפל ב-0** | **אסור** - הופך כל פסוק לאמת ($0 = 0$) | **אסור** |
| **העלאה בריבוע** | מותר - אבל **עלולים להיווסף פתרונות** | רק אם **שני האגפים חיוביים** |

**כלל זהב**: פעולה שאינה **שקולה** (העלאה בריבוע, הוצאת שורש, כפל בביטוי שעשוי להיות 0) **משנה את קבוצת הפתרונות**. לכן **בודקים** את הפתרונות **במשוואה המקורית**.

**אסור לחלק ב-0!** לדוגמה, ב-$x^2 = 3x$ - **אסור** לחלק ב-$x$ (מאבדים את $x = 0$). נכון: $x^2 - 3x = 0 \Rightarrow x(x - 3) = 0 \Rightarrow x = 0$ או $x = 3$.

### משוואה ממעלה ראשונה

מעבירים את כל מה שקשור לנעלם **לאגף אחד**, מוציאים אותו כ**גורם משותף**, ומחלקים.

### משוואה ממעלה שנייה

‏$ax^2 + bx + c = 0$ ($a \neq 0$) - **נוסחת השורשים**:

$$x_{1,2} = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

**הדיסקרימיננטה** $\Delta = b^2 - 4ac$ קובעת את **מספר הפתרונות**: $\Delta > 0$ - שניים; $\Delta = 0$ - אחד; $\Delta < 0$ - אין.

#### אי-שוויון ממעלה שנייה

**תמיד משרטטים את הפרבולה!**

1. מוצאים את **השורשים** (נקודות החיתוך עם ציר $x$).
2. משרטטים: $a > 0$ - "**מחייכת**" (∪); $a < 0$ - "**עצובה**" (∩).
3. **קוראים מהשרטוט**: $> 0$ - איפה הגרף **מעל** הציר; $< 0$ - **מתחת**.

**דוגמה**: $x^2 - x - 6 > 0$. השורשים: $-2, 3$. פרבולה מחייכת - מעל הציר **מחוץ** לשורשים: $x < -2$ או $x > 3$.

### סוגי משוואות מיוחדות

- **דו-ריבועית** ($ax^4 + bx^2 + c = 0$) - **"טריק ה-$t$"**: מסמנים $t = x^2$ ופותרים משוואה ריבועית. אחר כך $x = \pm\sqrt{t}$ - רק עבור $t \ge 0$. (אותו טריק עובד גם עם $t = \frac{x}{y}$, $t = \sin x$...)
- **אי-רציונלית** (עם $x$ בתוך שורש) - **מבודדים** את השורש, **מעלים בריבוע**, פותרים, ו**חובה לבדוק** בהצבה במשוואה **המקורית**: פסוק שקר - הפתרון **נפסל**.
- **ערך מוחלט**:
  - ‏$|x| = a \iff x = \pm a$ (עבור $a \ge 0$).
  - ‏$|x| < a \iff -a < x < a$.
  - ‏$|x| > a \iff x < -a$ **או** $x > a$.

### מערכות

- **"וגם"** - מחפשים $x$ שמקיים **את שני** התנאים: **חיתוך** התחומים. אם לאחד אין פתרון - **לכל המערכת אין פתרון**.
- **"או"** - מחפשים $x$ שמקיים **לפחות אחד**: **איחוד** התחומים.
- **מערכת משוואות** - **הצבה** (מבודדים נעלם ומציבים) או **השוואת מקדמים** (מחברים/מחסרים משוואות).
- **חילוק משוואות** - אם $a = b$ ו-$c = d$ (ו-$c, d \neq 0$), אז $\frac{a}{c} = \frac{b}{d}$. שימושי מאוד ב[סדרות הנדסיות](#סדרות).

### אי-שוויון עם שברים

**לא** מכפילים במכנה (אולי הוא שלילי!). במקום זה:

1. מעבירים הכול **לאגף אחד** ומקבלים שבר אחד: $\frac{f(x)}{g(x)} > 0$.
2. בודקים מתי **המונה** חיובי, מתי **המכנה** חיובי.
3. **משלבים** (בטבלת סימנים): השבר חיובי כשהם **באותו סימן**.

**קיצור**: אם המונה והמכנה **ממעלה ראשונה**, אפשר להכפיל ב**ריבוע המכנה** (שהוא **תמיד חיובי**) - ולקבל אי-שוויון ריבועי.

### חקירת משוואה עם פרמטר

#### ממעלה ראשונה: $ax = b$

| מקרה | מספר פתרונות |
|---|---|
| ‏$a \neq 0$ | **פתרון יחיד**: $x = \frac{b}{a}$ |
| ‏$a = 0$, $b \neq 0$ | **אין פתרון** ($0 = b$) |
| ‏$a = 0$, $b = 0$ | **אינסוף פתרונות** ($0 = 0$) |

**השיטה**: מביאים לצורה $ax = b$, ו**לפני שמחלקים** בפרמטר - מציבים את הערכים שמאפסים אותו **בשורה שלפני החילוק**, ובודקים מה קורה.

#### ריבועית: $ax^2 + bx + c$ עם פרמטר

**א. כמה פתרונות?**

- ‏**$a \neq 0$ (פרבולה)** - לפי $\Delta$: חותכת את הציר ($\Delta > 0$, שני פתרונות), משיקה ($\Delta = 0$, אחד), "מרחפת" ($\Delta < 0$, אין).
- ‏**$a = 0$ (ישר)** - חותך את הציר (פתרון יחיד), מקביל לו (אין), או מתלכד איתו (אינסוף).

**ב. אי-שוויון שמתקיים לכל $x$:**

- **פרבולה** - "מרחפת" **בצד הנכון**: למשל $ax^2 + bx + c > 0$ לכל $x$ $\iff$ $a > 0$ **וגם** $\Delta < 0$. (עם $\ge$ - גם $\Delta = 0$.)
- **ישר** - רק אם הוא **מקביל לציר** ובצד הנכון.

**בסוף** - כותבים **סיכום** של כל המקרים.

### טיפים

- באי-שוויון כדאי לכתוב את **הקטן משמאל** - כמו על ציר המספרים: $-2 < x < 3$.
- "פונקציה גדולה מפונקציה" - מדברים על **ערכי ה-$y$**.

### שאלות לחזרה

- למה אסור לחלק ב-$x$ את המשוואה $x^2 = 5x$?
- פתור $\sqrt{x + 3} = x - 3$, ובדוק את הפתרונות.
- פתור $\frac{x - 1}{x + 2} \ge 0$.
- עבור אילו $m$ מתקיים $x^2 + mx + 4 > 0$ לכל $x$?

## בעיות מילוליות - תנועה והספק

### כללי

- **קוראים את כל השאלה** לפני שמתחילים.
- **מגדירים משתנים** בהתחלה, במילים: "נסמן ב-$v$ את מהירות הרוכב (קמ"ש)".
- **בניית המשוואות** - החלק החשוב ביותר, ושווה הכי הרבה נקודות.
- **יחידות** - דקות או שעות? מטרים או ק"מ? (20 דקות = $\frac{1}{3}$ שעה.)
- **מחלקים בפרמטר?** מראים שהוא **שונה מ-0**.
- **עונים על מה ששאלו** - ו**בתשובה מילולית**.
- **"יותר" ו"פחות"**: כשמשווים כמויות - **מוסיפים לקטנה** כדי להשוות לגדולה. "דנה הלכה 5 ק"מ **יותר** מיוסי": $D_{\text{Yossi}} + 5 = D_{\text{Dana}}$.

### השיטה: טבלה

1. משרטטים **טבלה** עם שלוש עמודות.
2. ממלאים לפי הנתונים - **שורה לכל גוף** (או לכל שלב).
3. **ברגע ששתי עמודות מלאות - משלימים את השלישית** (לפי הקשר ביניהן).
4. בונים **משוואה** - בדרך כלל מהעמודה **השלישית**, לפי המשפט בשאלה שעוד לא השתמשנו בו.

### בעיות תנועה

$$\text{מהירות} \times \text{זמן} = \text{דרך}$$

| | **מהירות** | **זמן** | **דרך** |
|---|---|---|---|
| גוף א' | ‏$v$ | ‏$t$ | ‏$vt$ |
| גוף ב' | ‏$v + 10$ | ‏$t - 1$ | ‏$(v + 10)(t - 1)$ |

**מקרים נפוצים:**

- **נפגשים** (יוצאים זה לקראת זה) - **סכום הדרכים** = המרחק ההתחלתי.
- **משיג** (יוצאים לאותו כיוון) - ברגע ההשגה **הדרכים שוות**.
- **נהר** - **עם הזרם**: מהירות הסירה **ועוד** מהירות הזרם. **נגד הזרם**: **פחות**.
- **תנועה בניצב** (אחד צפונה, אחד מזרחה) - המרחק ביניהם לפי **פיתגורס**.

**דוגמה**: רוכב יצא מ-A ל-B (60 ק"מ). שעה אחריו יצא מכונית, במהירות **גדולה ב-30 קמ"ש**, והם הגיעו **יחד**. מה מהירות הרוכב?

| | מהירות | זמן | דרך |
|---|---|---|---|
| רוכב | ‏$v$ | ‏$\frac{60}{v}$ | 60 |
| מכונית | ‏$v + 30$ | ‏$\frac{60}{v + 30}$ | 60 |

המכונית נסעה **שעה פחות**: $\frac{60}{v + 30} + 1 = \frac{60}{v}$. פותרים: $v^2 + 30v - 1800 = 0 \Rightarrow v = 30$ (הפתרון השלילי נפסל). **מהירות הרוכב 30 קמ"ש.**

### בעיות הספק

שני סוגים. **המשפט האחרון בשאלה** בדרך כלל מגלה איזה.

#### קצב עבודה

$$\text{קצב} \times \text{זמן} = \text{כמות עבודה}$$

| | **קצב** (כמות ליחידת זמן) | **זמן** | **סה"כ** |
|---|---|---|---|
| ברז | 2 קוב לשעה | 3 שעות | 6 קוב |

**זמן ליחידה אחת** = $\frac{\text{זמן}}{\text{כמות}}$ - ההופכי של הקצב.

#### חלקיות עבודה

כל העבודה = **1**. מי שמסיים את העבודה **לבד** ב-$a$ שעות, עושה בשעה $\frac{1}{a}$ ממנה.

| | **זמן לבד** | **זמן בפועל** | **חלק מהעבודה** |
|---|---|---|---|
| ברז א' | 5 שעות | 3 שעות | ‏$\frac{3}{5}$ |
| ברז ב' | 4 שעות | 3 שעות | ‏$\frac{3}{4}$ |

**המשוואה**: **סכום החלקים = 1** (כשהעבודה הושלמה). כאן $\frac{3}{5} + \frac{3}{4} > 1$ - כלומר הבריכה **התמלאה** לפני 3 שעות. **הזמן המשותף** $t$: $\frac{t}{5} + \frac{t}{4} = 1 \Rightarrow t = \frac{20}{9}$ שעות.

**תנועה בהספק** (נדיר): הדרך היא "העבודה".

### הנפשה: מפגש והשגה

שנו את המרחק ואת המהירויות, ובדקו מתי שני הגופים נפגשים: כשהם נעים זה לקראת זה המהירויות מתחברות, וכשאחד רודף אחרי השני הן מתחסרות.

- פועל א' מסיים עבודה ב-6 ימים ופועל ב' ב-3. כמה זמן ייקח להם יחד?

## סדרות

### כללי

**סדרה** - רשימה **מסודרת** של מספרים: $a_1, a_2, a_3, \ldots$. **האינדקס** $n$ הוא **מקום** האיבר - מספר **טבעי** (שלם וחיובי).

- **הצבה באינדקס**: כדי למצוא $a_{2n+1}$ - מחליפים **כל** $n$ בנוסחה ב-$2n + 1$.
- **האיבר הראשון מבין $n$ האחרונים** (בסדרה של $k$ איברים): $a_{k-n+1}$. (מתוך 7 איברים, 3 האחרונים מתחילים ב-$a_5$.)
- **איברים אמצעיים**: ב-$2n + 1$ איברים - $a_{n+1}$ באמצע. ב-$2n$ איברים - $a_n$ ו-$a_{n+1}$.
- **מעבר מחיובי לשלילי** - פותרים $a_n = 0$ (התוצאה לא חייבת להיות שלמה) ו**מעגלים**. כך גם מוצאים את האיבר **הקרוב ביותר** לערך מסוים.
- **סדרה מורכבת** - לפעמים אפשר **לפרק**: $a_n = 5n + 2^n$ - חשבונית ($5n$) ועוד הנדסית ($2^n$).
- **שתי סדרות** בשאלה? חלקו את הדף לשניים.

### סדרה חשבונית

**כל איבר** מתקבל מקודמו **בהוספת אותו מספר** $d$ (**הפרש**, difference):

$$a_{n+1} - a_n = d$$

| | נוסחה |
|---|---|
| **איבר כללי** | ‏$a_n = a_1 + (n - 1)d$ |
| **סכום** | ‏$S_n = \frac{(a_1 + a_n)n}{2} = \frac{[2a_1 + (n - 1)d]\,n}{2}$ |
| **תכונה** | כל איבר הוא **הממוצע החשבוני** של שכניו: $a_n = \frac{a_{n-1} + a_{n+1}}{2}$ |

- ‏$d > 0$ - **עולה**; $d < 0$ - **יורדת**; $d = 0$ - **קבועה**.
- **האיבר הכללי** הוא **פונקציה קווית** של $n$ (שיפועה $d$); **הסכום** - **ריבועית**.
- **כל חלק** של סדרה חשבונית (איברים רצופים) - גם הוא חשבוני, **עם אותו $d$**.

**הסיפור של גאוס**: $1 + 2 + \cdots + 100$ - הראשון ועוד האחרון $= 101$, וכך כל זוג; יש 50 זוגות: $5050$. זו בדיוק נוסחת הסכום.

### סדרה הנדסית

**כל איבר** מתקבל מקודמו **בכפל באותו מספר** $q$ (**מנה**, quotient), ו**האיבר הראשון שונה מ-0**:

$$\frac{a_{n+1}}{a_n} = q \qquad q \neq 0,\ a_1 \neq 0$$

| | נוסחה |
|---|---|
| **איבר כללי** | ‏$a_n = a_1 q^{n-1}$ |
| **סכום** ($q \neq 1$) | ‏$S_n = \frac{a_1(q^n - 1)}{q - 1}$. (אם $q = 1$: $S_n = na_1$) |
| **תכונה** | כל איבר הוא **הממוצע ההנדסי** של שכניו: $a_n^2 = a_{n-1}a_{n+1}$ |

**עולה או יורדת?**

| ‏$q$ | ‏$a_1 > 0$ | ‏$a_1 < 0$ |
|---|---|---|
| ‏$q > 1$ | **עולה** | **יורדת** |
| ‏$0 < q < 1$ | **יורדת** | **עולה** |
| ‏$q < 0$ | **לא עולה ולא יורדת** - הסימנים מתחלפים | |
| ‏$q = 1$ | **קבועה** | |

**כלי חשוב - חילוק משוואות**: נתון $a_3 = 12$ ו-$a_5 = 48$. מחלקים: $\frac{a_1q^4}{a_1q^2} = q^2 = 4$, ו-$a_1$ מצטמצם.

### סדרה הנדסית אינסופית מתכנסת

כש-$|q| < 1$ (כלומר $-1 < q < 1$), האיברים **שואפים ל-0** - וסכום **כל** האיברים **סופי**:

$$S = \frac{a_1}{1 - q}$$

**דוגמה**: $1 + \frac{1}{2} + \frac{1}{4} + \cdots = \frac{1}{1 - \frac{1}{2}} = 2$.

**סדרות שנגזרות מסדרה אינסופית** ($a_1$, $q$):

| מה עשו | איבר ראשון | מנה | סכום |
|---|---|---|---|
| **הפכו סימן** במקומות הזוגיים | ‏$a_1$ | ‏$-q$ | ‏$\frac{a_1}{1 + q}$ |
| **רק המקומות האי-זוגיים** | ‏$a_1$ | ‏$q^2$ | ‏$\frac{a_1}{1 - q^2}$ |
| **רק המקומות הזוגיים** | ‏$a_1q$ | ‏$q^2$ | ‏$\frac{a_1q}{1 - q^2}$ |
| **סכום כל שני סמוכים** | ‏$a_1(1 + q)$ | ‏$q$ | ‏$\frac{a_1(1 + q)}{1 - q}$ |
| **ריבועי האיברים** | ‏$a_1^2$ | ‏$q^2$ | ‏$\frac{a_1^2}{1 - q^2}$ |
| **מכפלת כל שני סמוכים** | ‏$a_1^2q$ | ‏$q^2$ | ‏$\frac{a_1^2q}{1 - q^2}$ |

### איברים במקומות זוגיים ואי-זוגיים

| | **המקורית** | **מקומות אי-זוגיים** | **מקומות זוגיים** |
|---|---|---|---|
| **מספר איברים** (מקורית $2n$) | ‏$2n$ | ‏$n$ | ‏$n$ |
| **מספר איברים** (מקורית $2n + 1$) | ‏$2n + 1$ | ‏$n + 1$ | ‏$n$ |
| **איבר ראשון** | ‏$a_1$ | ‏$a_1$ | ‏$a_2$ |
| **הפרש / מנה** | ‏$d$ / $q$ | ‏$2d$ / $q^2$ | ‏$2d$ / $q^2$ |

### הוכחה שסדרה חשבונית או הנדסית

| | **חשבונית** | **הנדסית** |
|---|---|---|
| **לפי איבר כללי** | מראים ש-$a_{n+1} - a_n$ **קבוע** (לא תלוי ב-$n$) | מראים ש-$\frac{a_{n+1}}{a_n}$ **קבוע**, **וגם** $a_1 \neq 0$ |
| **לפי נוסחת סכום** | 1. $a_n = S_n - S_{n-1}$; 2. $a_{n+1} - a_n = d$; **3. בודקים ש-$a_1 = S_1$** | 1. $a_n = S_n - S_{n-1}$; 2. המנה קבועה; 3. $a_1 \neq 0$; **4. $a_1 = S_1$** |

**למה השלב $a_1 = S_1$?** כי $a_n = S_n - S_{n-1}$ נכון רק מ-$n = 2$ (אין $S_0$).

**הנימוק במילים**: "ההפרש בין כל שני איברים סמוכים קבוע - ולכן הסדרה חשבונית".

### כלל נסיגה

**כלל נסיגה** - נותנים את **האיבר הראשון** ו**קשר** בין כל איבר לקודמו.

| חשבונית | הנדסית | כללית |
|---|---|---|
| ‏$a_1 = a$, $a_{n+1} = a_n + d$ | ‏$a_1 = a$, $a_{n+1} = a_n q$ | ‏$a_1 = 2$, $a_{n+1} = na_n - 6n + 5$ |

- **יתרון**: מתאר **כל** סדרה.
- **חיסרון**: כדי למצוא איבר צריך **לחשב את כל קודמיו**.
