# העלייה הראשונה והשנייה

**העלייה הראשונה** (1882-1903) ו**העלייה השנייה** (1904-1914).

## הסיבות לעלייה

1. **גלי האנטישמיות** (לשתי העליות) - **"סופות בנגב"** ברוסיה (1881) וחוקים מפלים; **פרעות קישינב** (1903) - כ-50 נרצחו ומאות נפצעו. היהודים הבינו שרק **בארץ משלהם** יהיו בטוחים.
2. **פולמוס אוגנדה** (לעלייה השנייה) - רבים מהעולים התנגדו לתכנית אוגנדה, ועלו **כהפגנה** של הקשר לארץ ישראל.
3. **כישלון המהפכה ברוסיה** (1905, לעלייה השנייה) - יהודים סוציאליסטים קיוו להשתלב במהפכה, אבל **נדחו**. הם עלו כדי **לשלב ציונות וסוציאליזם**: התיישבות + שוויון ושיתוף.

## מאפייני העולים

| | **העלייה הראשונה** | **העלייה השנייה** |
|---|---|---|
| **מאין** | רוסיה ורומניה (וקבוצה מתימן) | מזרח אירופה (וקבוצה מתימן) |
| **מי** | **משפחות** | **צעירים** עד גיל 25, **רווקים**, משכילים, הרבה נשים |
| **דת** | **שומרי מסורת** | רובם **חילונים** - חלק ממרד בעולם הדתי |
| **אידאולוגיה** | | **סוציאליזם**: שוויון ושיתוף |
| **ארגון** | **לא מאורגנת** (התנועה הציונית עוד לא קמה) | מאורגנת יותר, במסגרות פוליטיות |

## הקשיים

1. **חוסר ידע בחקלאות** - יבולים רבים נכשלו.
2. **אקלים חם ומחלות** (בעיקר **מלריה**) - תמותה גבוהה.
3. **גניבות** של יבולים ובהמות מהמושבות.

## צורות ההתיישבות

### המושבה (העלייה הראשונה)

יישוב חקלאי שבו לכל איכר **בעלות פרטית** על אדמתו ומשקו.

- **משק חד-ענפי** - כל מושבה התמחתה בגידול אחד (למשל ענבים או הדרים).
- **אופי מסורתי**.
- **עבודה שכירה** - האיכרים העסיקו **פועלים ערבים**, וגם שומרים ערבים.

**גושי המושבות:**

- **יהודה:** פתח תקווה, ראשון לציון, נס ציונה, גדרה, רחובות.
- **שומרון:** זיכרון יעקב, חדרה.
- **גליל:** ראש פינה, מטולה.

### הקבוצה (העלייה השנייה) - דגניה

יישוב **שיתופי** קטן, המבוסס על **שוויון, אחריות הדדית ושיתוף**:

- **החלטות משותפות** בכל תחום - כלכלי, חברתי ואפילו אישי.
- **קופה, מטבח ומכבסה משותפים**.
- מגשים את רעיונות ה**"כיבושים"**, שמטרתם ליצור **"יהודי חדש"**:
  - **כיבוש האדמה** - האדמה בבעלות יהודית.
  - **כיבוש העבודה** - העבודה נעשית בידי יהודים.
  - **כיבוש השמירה** - שמירה עברית.
  - **כיבוש השפה** - עברית כשפת דיבור.

### ההתיישבות העירונית - תל אביב (1909)

- ב**יפו** חיו יותר מ-6,000 יהודים בתנאים קשים: צפיפות, לכלוך, סמטאות צרות.
- קבוצת משפחות התארגנה באגודה **"אחוזת בית"**, ובעזרת **המשרד הארץ-ישראלי**, **קק"ל** ו**הבנק הציוני** רכשה מגרשים.
- ב-**1909** הוקמה השכונה - **תל אביב**. בראש הוועד עמד **מאיר דיזנגוף**.

## הברון רוטשילד והעלייה הראשונה

**המניעים שלו:**

1. **הצלת יהודים** ממצוקה, בעיקר במזרח אירופה.
2. **מניעת התבוללות**, בעיקר של יהודי צרפת.
3. **יצירת חברה יהודית עובדת ויצרנית**.

**הפעולות:**

1. **עזרה כספית** למושבות (ראשון לציון, זיכרון יעקב, ראש פינה ועוד) - רובן עברו לחסותו.
2. **משטר אפוטרופסות** - **פקידים** ומומחים מטעמו ניהלו את המושבות וקבעו מה לגדל. כל מתיישב קיבל **קצבה** - לפי מידת הצייתנות שלו.
3. **שילוב חקלאות ותעשייה** - למשל **תעשיית היין** (יקבי ראשון לציון וזיכרון יעקב).
4. **תרבות צרפתית** - רופאים, גננות ומורים מצרפת; **ההוראה בצרפתית**.

| **ביקורת** | **תרומה** |
|---|---|
| **התעלמות מהאופי הלאומי** - הפקידים דיכאו את עצמאות האיכרים | **הצלת המושבות** מקריסה כלכלית |
| **תרבות צרפתית במקום עברית** | **שיפור החקלאות** ושילוב תעשייה |
| | **חידוש העלייה**, שנעצרה בגלל המשבר |

## המשרד הארץ-ישראלי (1908)

הוקם על ידי **ההסתדרות הציונית**, בראשות **ארתור רופין**.

**המטרות:**

1. **לקשר** את ההסתדרות הציונית להתיישבות בארץ.
2. **לחזק** את היישובים וליצור **רצף התיישבותי** (מעמק הירדן לשפלה).
3. **לעודד עלייה** ולסייע בקליטה - כדי ליצור **רוב יהודי**.
4. **לתכנן** את ההתיישבות לפי צרכים לאומיים.

**הפעולות:** הקמת **חוות לאומיות** ומימון **הקבוצה** (דגניה); סיוע ל**התיישבות העירונית** (תל אביב); עזרה ל**עולי תימן** בדיור ובפרנסה.

## מסגרות ארגוניות

### מסגרות כלכליות ופוליטיות

- **בעלייה הראשונה - אגודות האיכרים**, לפי ענפים: **"הפרדס"** (מגדלי הדרים, שיווק לחו"ל - ענף הייצוא המרכזי עד מלחמת העולם הראשונה), **"הכורמים"** (ניהלו את היקב בזיכרון יעקב).
- **בעלייה השנייה - שתי מפלגות פועלים**, שפעלו גם כארגונים חברתיים (לשכות עבודה, שירותי בריאות, עיתונים, מועדונים):

| | **הפועל הצעיר** (1905) | **פועלי ציון** (1906) |
|---|---|---|
| **הדגש** | **ציוני**: שילוב ציונות וסוציאליזם; כיבוש העבודה והאדמה; **עברית** | **סוציאליסטי-עולמי**: מלחמת מעמדות |
| **השפה** | עברית | בתחילה **יידיש** |
| **התיישבות** | תמכה | בתחילה התנגדה להתיישבות קבועה (רכוש פרטי) |

### מסגרות ביטחוניות - "כיבוש השמירה"

| | **בר גיורא** (1907) | **השומר** (1909) |
|---|---|---|
| **אופי** | **סודי**, מקומי; 7 מייסדים | **גלוי**, **ארצי** |
| **סיסמה / רעיון** | **"בדם ואש יהודה נפלה, בדם ואש יהודה תקום"** | יצירת **"יהודי חדש"** - חזק, עובד את אדמתו ומגן עליה |
| **פעילות** | שמירה בחוות **סג'רה** | שמירה ב**גליל** ובמושבות; חייב את המושבות להעסיק **פועלים יהודים**; הקים יישובים (**תל עדשים**, **כפר גלעדי**) |

**חשיבות השומר:** שינה את **דימוי היהודי** (מנרדף לגאה); עורר ארגוני שמירה נוספים; היה **הבסיס** לארגון ההגנה בשנות ה-20.

### החייאת השפה העברית

**אליעזר בן יהודה** (העלייה הראשונה) - קבע שלאומיות צריכה **ארץ, שפה ותרבות לאומית**. פעולותיו:

1. ייסד את העיתון **"הצבי"**.
2. יזם **בתי ספר** שלימדו בעברית.
3. הקים את **"ועד הלשון העברית"** - לחידוש מילים.
4. חיבר את **"מילון בן יהודה"**.

**המתנגדים:** **פקידי הברון** (שקידמו את הצרפתית) ו**הרבנים החרדים** (שראו בעברית המדוברת **חילול לשון הקודש**).

**העלייה השנייה:**

- **1909** - **גימנסיה הרצליה** בתל אביב: חינוך ציוני בעברית. גם **בצלאל** בירושלים לימד בעברית.
- **1913 - "מלחמת השפות"** - חברת **"עזרה"** (של יהודי גרמניה), שמימנה את **הטכניון**, דרשה ללמד בו ב**גרמנית** (כי לא היו ספרים מקצועיים בעברית). **המורים והפועלים** פתחו בשביתה ובמחאה, והמורים **התפטרו**. **התוצאה:** אחרי מלחמת העולם הראשונה הטכניון נפתח - **בעברית**.
