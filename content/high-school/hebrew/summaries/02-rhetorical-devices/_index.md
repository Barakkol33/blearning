# אמצעים רטוריים

**אמצעים רטוריים** הם כל הכלים הלשוניים העומדים לרשות הכותב כדי להשיג את מטרתו: לשכנע, להמחיש, להדגיש או למשוך את הקורא.

בבחינה בדרך כלל מבקשים שני דברים:

1. **לזהות** את האמצעי ולהביא דוגמה מהטקסט.
2. **להסביר את הערך הרטורי** - מה האמצעי תורם לטקסט ולמטרת הכותב.

## רשימת האמצעים

| אמצעי | הסבר | דוגמה |
|---|---|---|
| **דימוי** | השוואה בעזרת מילת דימוי (כ, כמו, כאילו) | "הוא רץ **כמו** צבי" |
| **מטאפורה** | השאלה - העברת תכונה ממשהו אחד למשהו אחר, בלי מילת דימוי | "ים של אנשים" |
| **האנשה** | מתן תכונות אנושיות לדבר שאינו אדם | "העיר נרדמה" |
| **הגזמה** | תיאור מוגזם כדי להדגיש | "חיכיתי נצח" |
| **חזרות** | חזרה על מילה או מבנה כדי להדגיש | |
| **מילים נרדפות** | כמה מילים באותה משמעות כדי לחזק רעיון | |
| **ניגודיות** | העמדת דברים מנוגדים זה מול זה | |
| **שדה סמנטי** | מילים מאותו תחום (למשל מילים מעולם המלחמה) | |
| **קונוטציה** | משמעות נלווית של מילה, מעבר למשמעות המילונית | "משטר" לעומת "שלטון" |
| **מילים מעצימות** | מילים שמגבירות את העוצמה (מאוד, ביותר, חסר תקדים) | |
| **יחסי מוען-נמען** | פנייה בגוף ראשון ושני ליצירת קרבה ("אנחנו", "אתם") | |
| **אירוניה** | אמירה שמשמעותה הפוכה מהנאמר | "איזה מזג אוויר נפלא" (בסופה) |
| **עירוב משלבים** | שילוב לשון גבוהה ולשון יומיומית | |
| **ניבים וביטויים** | צירופים קבועים | "לשים מקל בגלגלים" |
| **משחקי מילים** | שימוש בכפל משמעות או בצליל של מילים | |
| **שאלות ותשובות** | הכותב שואל ועונה בעצמו | |
| **שאלה רטורית** | שאלה שהתשובה עליה ידועה, ואין מצפים לתשובה | "האם יש מי שרוצה מלחמה?" |
| **הסתמכות על מקורות** | ציטוטים, נתונים ומומחים | |
| **הומור, חרוזים, פיסוק מיוחד** | | |

## מטרות האמצעים הרטוריים (הערך הרטורי)

כשמסבירים ערך רטורי, בוחרים מטרה מתאימה ומסבירים **איך** האמצעי משיג אותה בטקסט הספציפי:

- הוספת **ציוריות** לטקסט.
- **הבלטה או הדגשה** של רעיון.
- **המחשה** של רעיון מופשט.
- **העצמה** של רעיון.
- **הצגת עמדת הכותב** והבלטת כוונתו.
- **שכנוע** הנמענים.
- **משיכת** הנמענים ועניין אותם.
- יצירת **קרבה** עם הנמענים ושיתוף שלהם.
- יצירת **גיוון** (למשל בשאלות).
- **נזיפה** או הבעת **תמיהה**.
