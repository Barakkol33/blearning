# הבנה, רטוריקה וכתיבה

## סוגי טקסטים ונסיבות השיח

לפני שעונים על שאלות על טקסט, כדאי לזהות **איזה סוג טקסט** זה ו**באילו נסיבות** הוא נכתב. שני הדברים עוזרים להבין מה הכותב רוצה להשיג.

### סוגי טקסטים

| סוג | מטרה | מעורבות הכותב | דוגמאות |
|---|---|---|---|
| **טקסט מידעי** | להעביר מידע לנמען | אין מעורבות אישית - הכתיבה **אובייקטיבית** | ערך באנציקלופדיה, כתבה עיתונאית |
| **טקסט טיעוני** | להשפיע על הנמען ולשכנע אותו בעמדה | יש מעורבות אישית - הכותב מביע **עמדה** | מאמר דעה, נאום |
| **טקסט שימושי** | למסור מידע מעשי שהנמען ישתמש בו | אין | דף הוראות, דף מידע, מודעה |

- בטקסט טיעוני מחפשים את **העמדה** של הכותב ואת **הנימוקים** שלו.
- **פסקת טיעון** = עמדה (בעד / נגד) + נימוק.

### נסיבות השיח

הנסיבות הן "המידע מסביב לטקסט". הן עוזרות לשפוט עד כמה הטקסט אמין, למי הוא פונה ומה סוגו.

1. **כותרת**
   - **כותרת שקופה** - אפשר להבין ממנה בבירור מה נושא הטקסט.
   - **כותרת עמומה** - לא מאפשרת לדעת בוודאות מה הנושא. לעתים קרובות היא "פיקנטית", כדי לעורר סקרנות.
2. **מוען (הכותב)** - שמו, תפקידו ותוארו. מעידים על **מהימנות** הטקסט, על קהל היעד ולפעמים גם על סוג הטקסט. למשל, מאמר של רופא על בריאות אמין יותר ממאמר של אדם בלי הכשרה בתחום.
3. **במה** - היכן הטקסט פורסם (עיתון, אתר, כתב עת מקצועי). מעידה על **קהל היעד** ועל אופי הטקסט.
4. **זמן הפרסום** - עוזר לשפוט אם הטקסט עדיין **רלוונטי**. חשוב במיוחד בנושאים שמשתנים מהר, כמו טכנולוגיה וחדשות.


## אמצעים רטוריים

**אמצעים רטוריים** הם כל הכלים הלשוניים העומדים לרשות הכותב כדי להשיג את מטרתו: לשכנע, להמחיש, להדגיש או למשוך את הקורא.

בבחינה בדרך כלל מבקשים שני דברים:

1. **לזהות** את האמצעי ולהביא דוגמה מהטקסט.
2. **להסביר את הערך הרטורי** - מה האמצעי תורם לטקסט ולמטרת הכותב.

### רשימת האמצעים

| אמצעי | הסבר | דוגמה |
|---|---|---|
| **דימוי** | השוואה בעזרת מילת דימוי (כ, כמו, כאילו) | "הוא רץ **כמו** צבי" |
| **מטאפורה** | השאלה - העברת תכונה ממשהו אחד למשהו אחר, בלי מילת דימוי | "ים של אנשים" |
| **האנשה** | מתן תכונות אנושיות לדבר שאינו אדם | "העיר נרדמה" |
| **הגזמה** | תיאור מוגזם כדי להדגיש | "חיכיתי נצח" |
| **חזרות** | חזרה על מילה או מבנה כדי להדגיש | |
| **מילים נרדפות** | כמה מילים באותה משמעות כדי לחזק רעיון | |
| **ניגודיות** | העמדת דברים מנוגדים זה מול זה | |
| **שדה סמנטי** | מילים מאותו תחום (למשל מילים מעולם המלחמה) | |
| **קונוטציה** | משמעות נלווית של מילה, מעבר למשמעות המילונית | "משטר" לעומת "שלטון" |
| **מילים מעצימות** | מילים שמגבירות את העוצמה (מאוד, ביותר, חסר תקדים) | |
| **יחסי מוען-נמען** | פנייה בגוף ראשון ושני ליצירת קרבה ("אנחנו", "אתם") | |
| **אירוניה** | אמירה שמשמעותה הפוכה מהנאמר | "איזה מזג אוויר נפלא" (בסופה) |
| **עירוב משלבים** | שילוב לשון גבוהה ולשון יומיומית | |
| **ניבים וביטויים** | צירופים קבועים | "לשים מקל בגלגלים" |
| **משחקי מילים** | שימוש בכפל משמעות או בצליל של מילים | |
| **שאלות ותשובות** | הכותב שואל ועונה בעצמו | |
| **שאלה רטורית** | שאלה שהתשובה עליה ידועה, ואין מצפים לתשובה | "האם יש מי שרוצה מלחמה?" |
| **הסתמכות על מקורות** | ציטוטים, נתונים ומומחים | |
| **הומור, חרוזים, פיסוק מיוחד** | | |

### מטרות האמצעים הרטוריים (הערך הרטורי)

כשמסבירים ערך רטורי, בוחרים מטרה מתאימה ומסבירים **איך** האמצעי משיג אותה בטקסט הספציפי:

- הוספת **ציוריות** לטקסט.
- **הבלטה או הדגשה** של רעיון.
- **המחשה** של רעיון מופשט.
- **העצמה** של רעיון.
- **הצגת עמדת הכותב** והבלטת כוונתו.
- **שכנוע** הנמענים.
- **משיכת** הנמענים ועניין אותם.
- יצירת **קרבה** עם הנמענים ושיתוף שלהם.
- יצירת **גיוון** (למשל בשאלות).
- **נזיפה** או הבעת **תמיהה**.


## קשרים לוגיים ומילות קישור

**קשר לוגי** הוא היחס בין שני רעיונות: האם האחד הוא הסיבה של השני? האם הוא מנוגד לו? האם הוא מוסיף עליו? את הקשר מבטאים ב**מילות קישור**. בלעדיהן לטקסט לא היה רצף הגיוני.

בבחינה צריך לדעת:

1. **לזהות** את הקשר הלוגי בין שני חלקים בטקסט.
2. **להשתמש** במילות קישור מתאימות בכתיבה (בסיכום ובחיבור).
3. **להמיר** משפט מסוג אחד לסוג אחר בלי לשנות את הקשר הלוגי (ראו בהמשך הפרק).

### הקשרים הלוגיים

| קשר | מילות קישור לדוגמה |
|---|---|
| **ניגוד ועימות** | אך, אבל, אולם, אלא ש, ברם, מחד גיסא... מאידך גיסא, מצד אחד... ומצד שני, בניגוד לכך, ואילו, לעומת זאת, להפך, בעוד ש... |
| **הסתייגות (ויתור)** | אף על פי כן, עם זאת, למרות זאת, למרות ה..., חרף, בכל זאת, אמנם... אבל..., אף על פי ש, גם אם, אפילו, בכל אופן, מכל מקום, לכאורה... למעשה... |
| **סדר** | קודם כל, ראשית, שנית, תחילה, לאחר מכן, לבסוף, לסיום |
| **הוספה** | מלבד זאת, כמו כן, אף, יתרה מזו, יתר על כן, נוסף על כך, זאת ועוד, לא זו בלבד... אלא ש..., לא רק... אלא גם, וכן, חוץ מזה |
| **השוואה** | כפי ש, כשם ש, כמו ש, כאילו, בדומה לכך, באותה מידה, יחסית ל... |
| **הדגמה** | לדוגמה, למשל, דרך משל, כך למשל |
| **סיבה ותוצאה** | לכן, על כן, לפיכך, משום כך, שהרי, שכן, מפני ש, כיוון ש, מאחר ש, היות ש, הואיל ו, כתוצאה מכך, בשל כך, עקב כך, בגלל, בזכות, הודות ל... |
| **מעבר נושא** | ובכן, אם כן, בקשר ל..., בנוגע ל..., באשר ל... (לנושא שולי: דרך אגב, אגב) |
| **הסבר והבהרה** | דהיינו, קרי, כלומר, לאמור, במילים אחרות, זאת אומרת, הווה אומר, משמע, ליתר דיוק |
| **מסקנה** | מכאן ש..., מכאן נובע ש..., אי לכך, אם כך, לפיכך, ניתן להסיק ש... (מסקנה = רעיון חדש שנובע מהקודם) |
| **סיכום** | בסיכומו של דבר, לסיכום (סיכום = חזרה על מה שנאמר) |
| **הדגשה** | רק, בלבד, בייחוד, במיוחד, לא... אלא... |
| **תכלית** | כדי, למען, לשם כך, לצורך כך |
| **זמן** | לפני, אחרי, כאשר, ואז, לאחר מכן |
| **ברירה** | או, או ש |
| **תנאי** | אם, בתנאי ש, במקרה ש, אילו, לו |

**שימו לב:**

- **אִם** (תנאי) ≠ **גם אִם** (ויתור והסתייגות).
- **אך** (ניגוד) ≠ **ואילו** (עימות והשוואה).
- **מסקנה** מוסיפה רעיון חדש, ואילו **סיכום** רק חוזר על מה שנאמר.

### אותו קשר לוגי בשלושה סוגי משפטים

לכל קשר לוגי יש מילים מתאימות בכל סוג משפט:

- במשפט **פשוט** - בדרך כלל **מילת יחס** לפני שם (בגלל הגשם).
- במשפט **מאוחה** - **מילת קישור** אחרי פסיק (..., ולכן...).
- במשפט **מורכב** - **מילת שעבוד** שפותחת פסוקית (מפני ש...).

דוגמה - קשר של **ויתור והסתייגות**:

- משפט פשוט: **על אף** הגשם נצא לטיול.
- משפט מאוחה: יורד גשם, **ולמרות זאת** נצא לטיול.
- משפט מורכב: נצא לטיול **אף על פי ש**יורד גשם.

כדי להצליח בהמרות, כדאי לזכור לפחות מילה אחת מכל עמודה לכל קשר:

| קשר | משפט פשוט (מילות יחס) | משפט מאוחה (מילות קישור) | משפט מורכב (מילות שעבוד) |
|---|---|---|---|
| **סיבה ותוצאה** | בגלל, בשל, בזכות, עקב, בעקבות, הודות ל..., מחמת | ולכן, ועל כן, ולפיכך, ומשום כך, וכתוצאה מכך | מפני ש, משום ש, כיוון ש, כי, מאחר ש, היות ש, הואיל ו |
| **ניגוד** | - | אבל, אולם, אך, אלא, ברם | - |
| **ויתור והסתייגות** | למרות, על אף, חרף | ואף על פי כן, ובכל זאת, ולמרות זאת, ועם זאת | אף על פי ש, אפילו, גם אם, אם כי, אף ש |
| **עימות והשוואה** | - | ואילו, ולעומת זאת | - |
| **תכלית** | כדי ל..., למען, בשביל, לשם, לצורך | ולשם כך, ולצורך זה | כדי ש, פן, שמא, לבל |
| **הוספה** | - | ו, גם, בנוסף לכך, יתר על כן, כמו כן | - |
| **זמן** | לפני, אחרי, מאז, בזמן, במהלך | ואחר כך, ואז, ולאחר מכן, ולפני כן | כאשר, כש, לפני ש, אחרי ש, בזמן ש, עד ש |
| **הסבר** | - | כלומר, זאת אומרת, דהיינו | - |
| **ברירה** | - | או, או ש | - |
| **תנאי** | במקרה של, בלי, ללא | - | אם, לו, אילו, אלא אם כן, אלמלא, בתנאי ש |

### מילות קישור ומאזכרים

- **מילות קישור** יוצרות את הרצף בעל המשמעות בטקסט.
- **מאזכרים** - מילים שמפנות למשהו שהוזכר קודם (הוא, זה, הדבר הזה, התופעה). הם יוצרים **לכידות** בטקסט ומונעים חזרות. המאזכר מתאים למה שהוא מפנה אליו (המאוזכר) **במין ובמספר**.


## תפקידי סימני הפיסוק

סימני פיסוק לא רק מפרידים בין משפטים - הם גם נושאים **משמעות**. בבחינה שואלים מה תפקיד סימן פיסוק מסוים בטקסט, ולכן כדאי להכיר את התפקידים העיקריים של כל סימן.

### נקודה (.)

- מסיימת משפט.
- **נקודה בין מבעים קצרים שאינם משפטים מלאים** יוצרת **מתח** ואווירה דרמטית.
  דוגמה: לילה. חושך. מכונית שחורה.

### מירכאות ("...")

1. **שם של יצירה או ארגון** - סרט, ספר, הצגה, עיתון, ארגון (אבל לא שם של אדם ולא שם של מקום).
   דוגמה: קראתי את הספר "אש ולהבה".
2. **מושג או מונח מקצועי.** דוגמה: "הילדים הרעים" של הקולנוע.
3. **מילה או צירוף במשמעות מושאלת** (לא כפשוטם). דוגמה: הצבא קיבל "אור ירוק" לפעול.
4. **אירוניה** - לשון הפוכה, לשון סגי נהור. דוגמה: "הוא צדיק גדול".
5. **סלנג.** דוגמה: "פראיירים".
6. **ציטוט, מובאה או דיבור ישיר.** הערך הרטורי: ציטוט של הדובר משדר **אמינות**.
7. **הבלטת רעיון או מילה**, או סימון של ביטוי לא מדויק.

### נקודתיים (:)

1. **לפני פירוט** (אחרי ביטוי מכליל).
   דוגמה: אני מנוי על שלושה עיתונים: "מעריב", "ידיעות" ו"הארץ".
2. **לפני דיבור ישיר או ציטוט.** דוגמה: הרצל אמר: "אם תרצו, אין זו אגדה".
3. **לפני הסבר.** דוגמה: לבוש הוא חלק מתרבות: בני אדם משייכים אחרים לקבוצה מסוימת לפי בגדיהם.

### קו מפריד (-)

1. **במקום חלק חסר** באיבר השני של משפט מאוחה. דוגמה: היהפוך כושי עורו, ונמר - חברבורותיו?
2. **אחרי חלק ייחוד**, לשם הדגשה. דוגמה: ירושלים - שערים רבים לה.
3. **לפני ביטוי מסכם** (אחרי פירוט). דוגמה: חיילי גבעתי, חיילי גולני וחיילי השריון - כל אלה הם חיילים קרביים.
4. **לפני פירוט או הסבר.** דוגמה: לדגל האיטלקי שלושה צבעים - ירוק, אדום ולבן.
5. **במשפט שמני, בין הנושא לנשוא.** דוגמה: התשלום - עליי!

**זוג קווים מפרידים** באמצע משפט מסמן הערה צדדית (מאמר מוסגר) או פירוט.

### סוגריים ( )

1. **הערה**, לפעמים צינית. דוגמה: רבים שיבחו את השחקן (והוא אפילו לא ידע שהוא כזה).
2. **הסבר או מידע נוסף**, לפעמים לשם הדגשה. דוגמה: נשיא המדינה משמש ישות ייצוגית בלבד (אין לו סמכויות ביצועיות ממשיות).
3. **תרגום** של מילה. דוגמה: במייבשי הכביסה יש חיישנים (סנסורים).
4. **דוגמה או פירוט.** דוגמה: היידיש תרמה לעברית מילים המציינות תכונות שליליות (שוויצר, קוטר, פראייר).
5. **מראי מקום והפניות.** דוגמה: ייפתחו מגמות חדשות (הפירוט בעמוד 4).

### שלוש נקודות (...) בתוך משפט

1. **אירוניה.**
2. **הפתעה.**
3. **הסתרת מחשבות או רגשות** של הכותב.
4. **השמטת מילים** בתוך ציטוט ארוך.

### סימן שאלה (?)

- מסיים **שאלה רגילה** או **שאלה רטורית**.

### סימן קריאה (!)

1. הבעת **תמיהה**.
2. הבעת **משאלה**.
3. **הדגשה**.
4. **החלטיות** ונימה נחרצת.
5. **הגזמה**.
6. **ציווי** או פקודה.

### סימן שאלה וסימן קריאה יחד (?!)

- מבטא **תמיהה**, הרבה פעמים אחרי שאלה רטורית.


## כתיבת סיכום (כתיבה ממזגת)

**כתיבה ממזגת** היא סיכום של שניים או שלושה טקסטים יחד, לפי **תבחינים** (קריטריונים) שהמטלה נותנת, למשל "הבעיה" ו"הפתרונות". המטרה היא לא לסכם כל טקסט בנפרד, אלא **למזג** אותם: לאחד מה שמשותף ולהנגיד מה שונה.

### שלבי העבודה

1. **קוראים את המטלה**, ואז את הטקסטים. מסמנים בצבע שונה כל תבחין.
2. **בונים טבלה**: התבחינים בשורות, הטקסטים בעמודות. בטבלה כותבים משפטים **קצרים**.

   |  | טקסט 1 | טקסט 2 | טקסט 3 |
   |---|---|---|---|
   | תבחין 1 |  |  |  |
   | תבחין 2 |  |  |  |

   אם המטלה מבקשת לסכם רק חלק מהטקסטים, משאירים את המספור המקורי כדי לא להתבלבל.
3. **מסמנים בטבלה** מה **משותף** לטקסטים (מאחד) ומה **שונה** ביניהם (מייחד).
4. **משפט פתיחה** (לא חובה): מציגים את הנושא, בלי שמות הכותבים.
5. **משפט הכותבים**: מציינים את **שמות המשפחה** של הכותבים, ובסוגריים את **שנת הכתיבה**, ובמה הם עוסקים. אין צורך בשמות המאמרים. ("מעובד על פי X" - X הוא הכותב.)
   המבנה: *כותב1 (שנה1), כותב2 (שנה2) וכותב3 (שנה3) עוסקים ב...*
6. **גוף הסיכום** - **פסקה לכל תבחין**:
   - כותבים שאמרו דבר דומה מצרפים לאותה טענה: "כותב1 וכותב2 טוענים ש..."
   - כותבים שחולקים מציגים בנפרד, עם מילת ניגוד ביניהם: "...לעומת זאת, כותב3 סבור ש..."
   - משמיטים ומכלילים לפי הצורך (ראו בהמשך).
7. **ביבליוגרפיה**: המאמרים לפי **סדר הא"ב של שמות המשפחה**. כל רישום לפי הסדר:
   שם משפחה, אות ראשונה של השם הפרטי עם גרש, (שנה). שם המאמר. המקום שבו פורסם.
   - הביבליוגרפיה **לא נספרת** במספר השורות של הסיכום.

### כללים חשובים

- **כל טענה משויכת לכותב שלה** (בשם המשפחה בלבד).
- **מגוונים את דרכי המסירה**:
  1. **דיבור ישיר** - מותר לצטט, אבל לא ציטוט ארוך.
  2. **דיבור עקיף** - "X טוען ש..."
  3. **הסגר** - "לדברי X", "לפי X".
  4. **דיבור משולב** - הכותב אומר כי "...".
- **מגוונים את פועלי ההבעה**: אמר, טוען, מזכיר, מדגיש, סבור, מציין, מוסיף, וגם "לדבריו", "לטענתו".
- **לא פותחים כל משפט בשם של כותב** - משתמשים במאזכרים ומאחדים טענות.
- **מילות קישור**: לא "ראשית... שנית...", אלא "ראשית... כמו כן... בנוסף...".
- כשמזכירים כותב כמה פעמים באותה פסקה, אין צורך לחזור על השנה. בפסקה חדשה - כן.
- אפשר להשתמש ב**כותרות תוכן** לכל תבחין.
- אפשר לסיים ב**מסקנה או המלצה**, גם אם רק אחד הכותבים ממליץ.
- כשמסכמים **טבלה או גרף** מתוך טקסט, מתמצתים את המידע למסקנה אחת.

### מה משמיטים בסיכום?

- דוגמאות (או מכלילים כמה דוגמאות לטענה אחת)
- אמצעים רטוריים
- פנייה בגוף ראשון ושני
- ציטוטים ארוכים
- הסברים מפורטים
- מילים נרדפות וחזרות

### דוגמה

**המטלה:** כתבו סיכום על פי שלושה טקסטים על הפגיעה בטבע בישראל. בסיכום כתבו על הבעיה ועל הפתרונות המוצגים בטקסטים.

|---|---|---|---|

**משפט פתיחה:** בשנים האחרונות הפגיעה בטבע בישראל הולכת ומחמירה, ונשאלת השאלה כיצד ניתן לפתור את הבעיה.
