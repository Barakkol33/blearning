# blearning

A personal knowledge hub that grows over time, kind of like a Wikipedia that I build myself: summaries, explanations, interactive animations and games, from kindergarten to university and technology.

**Site:** https://barakkol33.github.io/blearning/

| Area | Content |
|---|---|
| גן | Letter and number games |
| יסודי | Elementary school subjects |
| תיכון | Bagrut subjects |
| האוניברסיטה הפתוחה - מדעי המחשב | Open University CS courses (generated from the openu repo) |
| טכנולוגיה | Software development, DevOps, Claude guide |

- [STRUCTURE.md](STRUCTURE.md): where everything goes and how it is laid out.
- [SPEC.md](SPEC.md): requirements, stack, hosting and costs.

## Running locally

```
cd site
npm install
npm run dev
```

Then open http://localhost:4321/blearning/.
